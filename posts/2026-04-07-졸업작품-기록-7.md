# [ 졸업작품 기록 (7) ]

웹 대시보드 & 카카오톡 API 기술 스택 선정

Flask 서버 스택을 확정하고 나서 프론트엔드와 알림 쪽을 정리했다.
웹 대시보드는 어떻게 만들고, Flask랑 어떻게 연결할 것인지,
카카오톡 알림은 어떤 방식으로 보낼 것인지를 결정해야 했다.

## 웹 대시보드 기술 스택

### 번들러: Vite

```bash
npm create vite@latest dashboard -- --template react
```

한 줄이면 React 프로젝트 생성이 끝났다. Vite를 선택한 이유는 단순한데, 빠르고 설정이 거의 필요 없어서 졸업작품 규모의 프로젝트에 딱 맞는 수준이었다.

### Flask 연동 방식: REST API + 폴링

React가 주기적으로 Flask에 GET 요청을 날리는 방식인데, 폴링 인터벌은 3초로 잡았다.

폴링으로 충분하다고 판단한 이유가 있었는데, 대시보드의 목적은 로그 확인이고 실시간 알림은 카카오톡이 이미 담당하고 있기 때문이었다. 시연 흐름을 보면 이렇다.

```
소리 감지 → Flask 처리 → 카카오톡 알림 → 대시보드 갱신 (최대 3초 후)
```

카카오톡이 먼저 뜨고, 대시보드는 조금 뒤에 반영되는 구조인데 시연에서 충분히 납득 가능한 딜레이였다.

### UI 컴포넌트 라이브러리: shadcn/ui

Tailwind 기반 컴포넌트 라이브러리인데, 테이블, 카드, 배지 같은 컴포넌트가 이미 만들어져 있어서 로그 테이블이랑 상태 표시 화면을 빠르게 뽑을 수 있었다. 커스텀도 Tailwind 클래스로 바로 조정이 가능해서 선택했다.

### 접근성 UI

타겟이 5060 중증 청각장애 1인 가구인 만큼 일반적인 대시보드 설계랑은 달라야 했다.

- 스마트폰은 쓸 줄 알아도 앱 설치, 로그인 과정이 낯설 수 있음
- 고령이라 시력 저하가 동반된 경우도 있음
- 1인 가구라 오류 상황에서 도움 요청할 사람이 없음
- 텍스트 안내보다 직관적인 시각 신호에 익숙

이 네 가지를 고려해서 세 가지 접근성 요소를 설계했다.

#### ① 단계별 카카오 로그인 안내

- 큰 버튼, 단순한 화면 구성
- "1/3 완료" 같은 진행바로 얼마나 남았는지 시각적으로 표시
- 로그인 실패 시 "다시 시도" 버튼을 크게, 오류 메시지는 전문 용어 없이
- 설정 완료 후 테스트 알림 버튼 제공 → "지금 카카오톡 확인해보세요" → 실제 알림이 와야 안심

#### ② 첫 접속 시 전체 튜토리얼

처음 접속하면 기능을 하나씩 순서대로 안내

#### ③ 각 기능 옆 물음표 모달

어떤 기능인지 궁금할 때 바로 확인 가능

## 카카오톡 API

### 방식 선택

카카오 메시지 전송 방식은 두 가지가 있었는데,

- 나에게 보내기: 개발자 본인 계정으로만 전송 → 실사용 불가
- 친구에게 보내기: 사용자가 카카오 로그인 1회만 하면 그 계정으로 전송 가능

실제 사용자에게 알림을 보내야 하니까 친구에게 보내기 방식으로 확정했다.

### 전체 흐름

**최초 설치 시 1회만**

```
사용자가 웹 대시보드 접속
        ↓
카카오 로그인 버튼 클릭
        ↓
카카오 동의 화면 ("메시지 전송 허용")
        ↓
인가 코드 발급
        ↓
Flask가 인가 코드로 액세스 토큰 + 리프레시 토큰 발급
        ↓
SQLite에 저장
```

**소리 감지 시 매번**

```
ESP32 → Flask (WAV 전송)
        ↓
YAMNet 분류 완료
        ↓
액세스 토큰 유효 여부 확인
  ├── 유효 → 카카오 API 호출
  └── 만료 → 리프레시 토큰으로 재발급 → 카카오 API 호출
        ↓
사용자 카카오톡으로 알림 전송
        ↓
SQLite에 로그 기록
```

### 토큰 관리

| 토큰 | 유효 기간 | 역할 |
| --- | --- | --- |
| 액세스 토큰 | 6시간 | 실 API 호출에 사용 |
| 리프레시 토큰 | 60일 | 액세스 토큰 만료 시 재발급 |

```python
def send_kakao_message(access_token, sound_type):
    url = "https://kapi.kakao.com/v2/api/talk/memo/default/send"
    headers = {"Authorization": f"Bearer {access_token}"}
    payload = {
        "template_object": json.dumps({
            "object_type": "text",
            "text": f"[소리 감지] {sound_type}",
            "link": {"web_url": ""}
        })
    }
    response = requests.post(url, headers=headers, data=payload)
    if response.status_code == 401:  # 토큰 만료
        access_token = refresh_access_token()
        return send_kakao_message(access_token, sound_type)
    return response
```

## 정리

| 항목 | 선택 |
| --- | --- |
| 번들러 | Vite |
| 프레임워크 | React |
| Flask 연동 | REST API + 폴링 (3초) |
| UI 라이브러리 | shadcn/ui (Tailwind 기반) |
| 카카오 전송 방식 | 친구에게 보내기 |
| 토큰 저장 | SQLite |
| 토큰 갱신 | 액세스(6시간) + 리프레시(60일) 자동 갱신 |
