## 2. 세 조건 학습

real / plac / plac_cross 세 조건을 동일 설정으로 학습. soft token 4개.

gemma는 대사 하나가 들어갈 때

```
"됐다, 됐어"  →  [됐] [다] [,] [됐] [어]   토큰 5개
```

그럼 어조 벡터를 어디에 끼우냐.

k=1이면,

```
[어조토큰] 다음 대사의 감정은? "됐다, 됐어"  →  gemma
    ↑
  여기 한 칸
```

k=4라면

```
[어조1][어조2][어조3][어조4] 대사...
```

즉, 네 칸을 어떻게 만드냐. 원본은 숫자 63개이다. 이걸 gemma가 쓰는 크기인 2560개로 바꿔줘야 함.

```
k=1일 때:
  숫자 63개  →  변환기  →  숫자 2560개  →  한 칸에 넣음

k=4일 때:
  숫자 63개  →  변환기  →  숫자 10240개  →  2560씩 4토막 → 네 칸에 넣음
```

→ 변환기 출력을 4배로 만들어서 4등분하는 것.

## 3. 성분 분해

### 실험 배경

층2 기준점을 화자 전체 발화 평균에서 감정별 평균의 평균으로 변경하고 세 조건을 재학습. 기존 설계에서 어조는 두 성분으로 나뉨.

- 감정 수준 성분은 판단에 기여
- 발화 개별 성분은 판단을 방해
- → 두 힘이 서로 상쇄되어 합계가 0 근처에 머뭄

기준점 변경이 이 구조를 어떻게 바꾸는지가 이번 재설계의 핵심 물음.

### 작업 의미

- 감정 수준 성분 = 같은 감정 치환 − 다른 감정 치환
- 발화 개별 성분 = 진짜 어조 − 같은 감정 치환

학습 데이터, 학습량, seed, 하이퍼 파라미터, 소프트 토큰 수는 두 설계에서 모두 동일.

### 결과

**[ 그래프 ]** 세로축은 정답률 차이이며, 0선 위가 판단에 도움, 아래가 방해를 뜻함.

**[ 해석 ]** 두 성분이 모두 유리한 방향으로 움직임.

- 판단에 기여하던 성분은 +2.18%p에서 +2.66%p로 커졌음
- 판단을 방해하던 성분은 −2.32%p에서 −1.75%p로 방해가 줄었음
- → 그 결과 합계 부호가 뒤집힘

이 자료가 보이는 것은 순효과가 음수에서 양수 영역으로 이동했다는 사실.

## 4. 구간별 확인

### 실험 배경

기존 설계에서 감정 수준 성분의 기여는 두 라벨이 어긋나는 구간에만 나타남. 두 라벨이 일치하는 구간에서는 +0.25%p로 사실상 0이었고 통계적으로도 우연과 구분되지 않았음.
→ 층2 기준점을 감정별 평균의 평균으로 바꾼 뒤 이 구조가 유지되는지 확인했음.

### 결과

**[ 그래프 ]** 가로축의 두 지점은 성격이 다른 두 집단.

- 왼쪽은 대사 감정과 목소리 감정이 서로 다른 발화.
- 오른쪽은 두 라벨이 같은 발화.

**[ 결과 해석 ]** 기존 설계에서는 어조는 대사가 딴소리하는 구간에서만 작동함.

- → 새 설계에서는 일치 구간의 기여가 +3.90%p로 올라감
- 불일치 구간의 기여는 3.27%p에서 +1.95%p로 줄었음
- 전체 기여가 커진 것은 두 구간의 합이지 모든 구간에서 개선된 것이 아님

따라서 어조가 텍스트가 무너지는 자리에서만 작동한다는 기존 진술은 새 설계에서 성립하지 않는다. 두 설계에서 어조가 작동하는 위치 자체가 다름.

다만 왜 작동 위치가 바뀌었는지는 규명되지 않음. → 측정된 것은 위치가 이동했다는 사실이며, 그 기제는 확인되지 않음.

## 5. 애매함 지표 생성

### 실험 배경

랩미팅 피드백에서 오디오 모듈의 역할이 세 상황으로 구분되었음.

- 텍스트 감정이 뚜렷하면 오디오가 필요 없고
- 텍스트 감정이 애매하면 오디오가 힌트를 주며
- 비꼼이나 강요된 동의에서는 오디오가 텍스트와 다른 방향을 가리킴

기존 구간 분할인 라벨 일치 여부는 두 라벨이 같은지만 알려주며 대사만으로 감정을 판단할 수 있는지와는 별개의 정보.
→ 애매함을 재는 지표를 먼저 만들고 그것이 실제 판단 난이도를 반영하는지 확인.

### 작업 의미

텍스트 임베딩으로 감정 8종을 예측하는 선형 분류기를 화자 80명으로 학습시키고 평가 화자 20명의 각 발화에서 8개 확률 중 최댓값을 텍스트 확신도로 정의. 정답 라벨 = 소리 감정을 사용함 → 본 실험의 채점 라벨과 동일한 기준 사용.

### 결과

**[ 그래프 ]**

- 가로축: 텍스트 확신도 = 대사만으로 감정을 예측했을 때 1위 감정의 확률. 즉, 오른쪽으로 갈수록 대사만으로 감정이 뚜렷하다는 것
- 세로축: 그 구간에 속한 발화들의 실제 정답률 = 대사만으로 소리 감정을 맞힌 비율 → 확신도가 실제 판단 성공과 연결되는지를 보여줌
- 붉은 점선: 확신도 중앙값 0.435 → 이 선을 기준으로 확신 낮음과 확신 높음을 나눔
- 막대 아래 회색 수치는 각 구간의 발화 수

**[ 그래프가 의미하는 것 ]**

- 확신도가 높을수록 실제 정답률도 높음
- 최저 구간에서 최고 구간까지 3배 차이 → 확신도가 실제 판단 난이도를 반영하는 지표

따라서 이 값으로 발화를 나누면 대사만으로 판단이 서는 발화와 그렇지 않은 발화를 구분 가능. 이 자료가 보이는 것은 지표의 타당성이지, 이 구간 구분이 어조 기여와 연결되는지는 별도 측정이 필요함.

## 6. 텍스트 애매함 구간 어조 기여 실험

### 실험 배경

앞 자료에서 텍스트 확신도가 실제 판단 난이도를 반영하는 지표임을 확인. → 이 값을 두 번째 축으로 삼아 네 칸으로 나눔.

라벨 일치 여부와 텍스트 확신도는 별개의 정보.

- 라벨이 일치해도 대사만으로 감정이 뚜렷하지 않을 수 있고
- 라벨이 어긋나는 대사도 확신에 차 있을 수 있음

### 작업 의미

감정 수준 성분 = 같은 감정 치환 − 다른 감정 치환. → 두 조건 모두 발화별 개별 대응이 끊겨 있으므로 차이는 감정 수준 정보에서만 발생.

### 결과

**[ 그래프 ]** 가로축은 4개의 구간.

- 앞 두 칸은 텍스트 감정 라벨과 음성 감정 라벨이 일치하는 발화
- 뒤 두 칸은 어긋나는 발화

각 쌍 안에서

- 진한 막대는 텍스트 확신도가 중앙값 이상인 발화
- 연한 막대는 중앙값 미만인 발화

세로축: 감정 수준 성분의 기여 → 값이 클수록 그 구간에서 어조의 감정 정보가 판단을 많이 개선했다는 뜻.

**[ 그래프 해석 ]**

- 4칸 모두에서 감정 수준 성분이 양수 → 어조의 감정 정보는 텍스트 상황과 무관하게 판단에 기여함

각 쌍 안에서 텍스트 확신도가 낮은 쪽의 기여가 더 큼.

- 다만 이 차이는 통계적으로 확인되지는 않았음
- 부트스트랩 검정에서 두 구간 모두 신뢰구간이 0을 포함하며 표본을 다시 뽑으면 부호가 뒤집힐 수 있는 범위

따라서 텍스트가 애매한 구간에서 어조가 더 기여한다는 진술은 이 자료로 성립하지 않는다.

- 값의 방향은 해당 구조와 맞지만 우연 범위를 벗어나지 못함
- 이는 효과가 없다는 뜻이 아니라 이 표본 크기로는 판별되지 않는다는 뜻
