## 2. LoRA 부착

- 모델의 텍스트부(language_model)는 layer 42층
- 앞 24층: q·k·v·o 4개씩 → 24×4 = 96
- 뒤 18층: KV 공유라 k·v 없음, q·o 2개씩 → 18×2 = 36
- 96 + 36 = 132

즉, 이 132개가 LoRA 부착할 수 있는 전체 자리이다.

## 4. 4-way CER 실험

파인튜닝이 진짜로 "오디오를 더 듣게" 만들었는지 확인하는 실험

```
             정상 오디오    무음 오디오
base          CER_b_n      CER_b_s   -> 비교하는 4가지 경우
finetuned     CER_f_n      CER_f_s

audio-gap(base)      = CER_b_s - CER_b_n
audio-gap(finetuned) = CER_f_s - CER_f_n

헤드라인: audio-gap이 파인튜닝 후 커졌는가?
(gap 증가 → 파인튜닝이 오디오 의존도를 높였다는 증거)
```

- 확인 방법: 무음 오디오를 제공

오디오를 진짜 듣는 모델이라면 무음 줬을 때 전사를 못해서 CER(오류율)이 크게 올라가야 함
오디오를 안 듣는 모델은 무음이든 정상이든 LLM이 알아서 뭔가를 만들어내니까 CER 차이가 별로 없음

그래서 4가지 경우 비교

- 파인튜닝 후 "무음 - 정상" 차이(audio-gap)가 base보다 커졌으면 **파인튜닝이 오디오 의존도를 높였다** 증명
- 차이가 별로 없으면 파인튜닝이 텍스트 패턴만 외운 것, 오디오는 여전히 무시

audio-gap이 크면 오디오에 의존하고 있다는 뜻
audio-gap이 0 또는 음수면 무음이 오디오를 듣는 거보다 잘 듣거나 똑같다는 얘기니까 오디오를 무시한다는 뜻이다.(환각)

### 짧은 발화 상세 비교

> 위 4가지 CER 비교 실험에서 짧은 발화에서의 audio-gap이 base 모델에서 finetuned 모델로 변환될 때 음수에서 양수 전환됐는데 이  개선이 ***"오디오 의존 상승"*** 때문인지 ***환각성 과생성 억제*** 부산물인지 구분하기 위해 짧은 발화 5개의 base/finetuned 예측을 비교
> ![](https://velog.velcdn.com/images/xorms/post/0d328c23-dbfc-47e7-b2c0-98a63c23ec3a/image.png)

#### 케이스별 관찰 )

[1][2]: finetuned가 참조를 정확히 전사 -> 오디오를 실제 활용(진짜 개선)
[0]: base는 챗봇 모드 환각("제가 한국어로 전사해 드릴게요"), finetuned는 다른 환각("어떤 점이 궁금하신가요?") -> 둘 다 오답
[3]: base는 정답 뒤 지시문 누출("이 음성을 한국어로 전사하세요"), finetuned는 완전 무관 환각 -> finetuned가 오히려 더 엉뚱(반례)
[4]: 둘 다 오답

#### 해석 )

짧은 발화의 CER 개선은 "오디오 의존 상승 + 환각성 과생성 억제"의 혼합

- 절제 효과: base의 지시문 누출/챗봇 환각이 finetuned에서 사라짐 -> short cer_normal 1.21 -> 0.71 개선의 상당 부분
- 오디오 의존: [1][2]에서 내용까지 정확히 맞힘
- 한계: finetuned도 환각 잔존([0][3][4]), [3]은 base보다 악화
