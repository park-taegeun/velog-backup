## 무엇이 문제인가
지난 글의 결론은 "채점이 필요한데 계산 자원이 없어 불가능하다"였음
랩 GPU 워크스테이션을 쓸 수 있게 되면서 채점을 다시 열 수 있게 됨

그런데 서버에 있던 것은 체크포인트만이 아님
학습에 넣던 126차 데이터 파일도 함께 사라짐

다시 만들면 되지만 문제가 하나 있음
- 학습 데이터는 여러 단계를 거쳐 만들어짐
- 마지막 두 단계(감정균등 층2, 층1 표준화 결합)는 노트북 셀 안에서만 실행됐고 스크립트가 없음

다시 만든 데이터가 서버와 조금이라도 다르면
-> 이후 결과가 서버와 달라졌을 때 원인이 재학습인지 데이터인지 구분할 수 없음

따라서 학습 전에 "서버와 같은 데이터인가"부터 확인해야 함

## 무엇을 다시 만들었나

```
AI-Hub 원본 (5개 배치)
↓ 발화 표 만들기 (1.5초 이상)
↓ 63차 추출 (층1)
↓ 학습 데이터 + 대조군 짝 (plac / plac_cross)
↓ 감정균등 층2 ← 노트북 셀에만 있던 계산
↓ 층1 표준화 + 결합 ← 노트북 셀에만 있던 계산
126차 학습 데이터
```

앞 단계는 저장소에 남아 있던 스크립트를 그대로 실행
마지막 두 단계는 서버 노트북의 셀 계산을 숫자 하나 바꾸지 않고 스크립트로 옮김

대조군 짝은 한 가지 더 까다로웠음
- 서버 파일에는 짝지어진 벡터 값만 있고, 어느 발화와 짝지었는지는 따로 저장되지 않음
- 그래서 벡터 값을 대조해 짝의 출처를 거꾸로 찾아냄
