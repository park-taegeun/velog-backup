# [ 졸업작품 기록 11 ]

초인종 유사도 검증 기법 확정 — SP/DTW + cosine distance

교수님 피드백 중 세 번째였던 "DTW랑 코사인 유사도를 합쳐보는 방식을 고려해봐라"를 받고 나서
먼저 기존 방식의 한계를 다시 들여다봤고, 논문을 찾아봤다.
결론부터 말하면 SP/DTW + cosine distance 조합으로 확정했다.

## 유사도 검증이 쓰이는 위치

```
소리 발생
    ↓
ESP32 감지
    ↓
Flask → YAMNet 1차 분류 ("초인종"으로 분류됨)
    ↓
PIR 확인 (사람 있음?)
    ↓
ToF 확인 (1.5m 이내?)
    ↓
★ 유사도 검증 ★
    ↓
카카오톡 알림
```

YAMNet, PIR, ToF를 전부 통과한 이후 마지막 관문이다. 여기서 등록된 내 집 초인종 소리랑 실제로 일치하는지 확인한다.

## 기존 방식(코사인 유사도)의 한계

처음에는 멜 스펙트로그램을 1D로 펼쳐서 코사인 유사도 한 번으로 비교하는 방식을 썼다.

```
템플릿 멜스펙트로그램(2D) → 1D로 펼치기 → [0.2, 0.5, 0.1, 0.8, ...]
새 소리 멜스펙트로그램(2D) → 1D로 펼치기 → [0.2, 0.4, 0.1, 0.7, ...]
                ↓
        두 벡터 사이 각도 계산
                ↓
        유사도 점수 (0~1)
```

문제는 2초 고정 패딩에서 생겼다. 초인종을 짧게 누르거나 길게 눌렀을 때 2초 안에 들어가는 패딩값이 달라지는데, 소리 자체는 똑같은 내 집 초인종인데도 1D로 펼쳤을 때 벡터 구조가 달라져서 코사인 유사도가 "다른 소리"로 볼 가능성이 생겼다.

코사인 유사도는 위치 대 위치 비교 방식이라, 시간축이 조금만 어긋나도 불리해지는 구조였다.

## DTW가 이 문제를 해결하는 방식

DTW(Dynamic Time Warping)는 가장 잘 맞는 위치끼리 비교하는 알고리즘이다. 시간축을 유연하게 늘리거나 줄여서 소리의 실제 내용이 있는 부분끼리 대응시킨다.

구체적으로는 두 소리의 모든 프레임 조합 사이의 거리를 계산해서 비용 행렬을 만들고, 그 중 가장 비용이 낮은 경로를 찾아서 유사도를 측정한다.

```
          감지T1  감지T2  감지T3  감지T4
등록T1  [  ?      ?      ?      ?  ]
등록T2  [  ?      ?      ?      ?  ]
등록T3  [  ?      ?      ?      ?  ]
등록T4  [  ?      ?      ?      ?  ]
```

? 자리에 들어가는 숫자가 두 프레임 사이의 거리인데, 숫자가 작을수록 그 두 프레임이 비슷하다는 뜻이다. DTW는 이 행렬에서 가장 비용이 낮은 경로를 찾아 전체 유사도를 계산한다.

## 거리 함수로 코사인을 쓰는 이유

비용 행렬에서 프레임 간 거리를 계산하는 방법은 크게 두 가지다.

- **유클리드 거리** — 두 벡터 사이 직선 거리, 절대적인 값 차이에 민감하다.
- **코사인 거리** — 1 - 코사인 유사도, 두 벡터가 가리키는 방향 차이만 본다.

우리 시스템에서 코사인 거리가 더 적합한 이유가 있었다.

- 초인종 소리를 등록할 때: 조용한 실내 환경에서 녹음
- 초인종 소리를 감지할 때: 복도 소음이 있는 환경에서 녹음

볼륨(진폭)이 달라질 수 있는데, 소리의 주파수 패턴(방향)은 같다.

```
유클리드 거리를 쓰면:
  등록 프레임 = [0.2, 0.4, 0.8]
  감지 프레임 = [0.4, 0.8, 1.6]  ← 볼륨 2배
  → 거리가 크게 나옴 → 다른 소리로 판단할 수 있음

코사인 거리를 쓰면:
  방향이 완전히 같음 → 거리 = 0 → 같은 소리로 판단
```

## 논문 근거

교수님 피드백을 받고 관련 논문을 찾아봤는데, PubMed Central에서 딱 맞는 연구를 찾았다.

> Pitch- and spectral-based dynamic time warping methods for comparing field recordings of harmonic avian vocalizations (PMC3745477)

케냐 야외에서 녹음한 새 울음소리 2,116개를 가지고 여러 알고리즘의 분리 성능을 비교한 연구인데, 그 중 SP/DTW + cosine distance 조합이 스펙트로그램 기반 방식 중 가장 높은 분리 성능을 보였다.

코사인이 유클리드보다 좋았던 이유를 논문에서 직접 설명하는데, 코사인 메트릭은 스펙트럼의 파워에 대해 정규화되어 있어서 형태(shape)의 차이를 강조하는 반면, 유클리드 메트릭은 전체 파워 차이에도 민감하게 반응한다는 내용이었다.

논문의 실험 환경이 평균 SNR 3.3dB의 열악한 야외 녹음이었는데, 우리 시스템의 복도 환경은 이보다 훨씬 양호하고, 문제 구조도 동일했다. 매번 녹음 음량이 달라도 패턴으로 같은 소리와 다른 소리를 구분해야 한다는 조건이 같았다.

## 연산량 문제: FastDTW

기존 DTW의 계산량이 O(N²)인데, FastDTW를 쓰면 O(N)으로 줄어든다. 2초짜리 오디오 클립에 적용하면 연산량이 극히 작고, 이미 YAMNet + PIR + ToF를 통과한 이후에만 실행되는 구조라서 t2.micro 환경에서도 5초 요건을 충분히 맞출 수 있다고 판단했다.

## 최종 확정

```
등록 시: 녹음 → 멜스펙트로그램(2D) → SQLite 저장
감지 시: 소리 → 멜스펙트로그램(2D) → FastDTW(거리 함수: cosine) → 유사도 점수
```

임계값은 초인종 구매 후 실측 테스트를 통해 결정할 예정이고, 초기값은 0.8 이상을 기준으로 잡고 조정할 계획이다.
