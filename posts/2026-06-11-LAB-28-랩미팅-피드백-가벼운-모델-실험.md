## E2B BF16 재실험
### 본 실험의 목적
- 환각 원인이 LLM 쪽 NF4 양자화인지, instruction-tuned 생성 모델의 구조적 회귀인지 가르는 대조 실험
- E4B NF4 세팅의 짧은 발화 환각이 양자화 제거 시 사라지는지 확인

### 실험 과정
#### 1. 모델 로드
```python
# 모델 로드 + VRAM 실측
import torch
from collections import Counter
from transformers import AutoProcessor, Gemma4ForConditionalGeneration

MODEL_ID = "google/gemma-4-E2B-it"

torch.cuda.empty_cache()
torch.cuda.reset_peak_memory_stats()

processor = AutoProcessor.from_pretrained(MODEL_ID)
model = Gemma4ForConditionalGeneration.from_pretrained(
    MODEL_ID,
    dtype=torch.bfloat16,          # transformers v5.x: torch_dtype 아님
    device_map={"": 0},
    attn_implementation="sdpa",
)
model.eval()

# VRAM 실측
alloc = torch.cuda.memory_allocated() / 1024**3
reserved = torch.cuda.memory_reserved() / 1024**3

# dtype 감사: 양자화/fp32 오염 없이 전체 bf16인지 (이번 실험 전제 검증)
dtypes = Counter(str(p.dtype) for p in model.parameters())

print(f"loaded: {MODEL_ID}")
print(f"param dtype 분포: {dict(dtypes)}")
print(f"VRAM allocated: {alloc:.3f} GB / 11.94 GB ({alloc/11.94*100:.1f}%)")
print(f"VRAM reserved : {reserved:.3f} GB")
```

#### 2. 전체 ASR 성능
![](https://velog.velcdn.com/images/xorms/post/489b31fa-13cf-4681-affa-d4ffa09b8faa/image.png)
- E2B BF16 전체: mean CER 0.342 / median 0.211 / 환각률(CER>1.0) 4.2%
- E4B NF4(nb08) 대비: mean 0.579 to 0.342, median 0.231 to 0.211, 환각률 12.6% to 4.2%
- median은 거의 불변(핵심 전사력 동일), mean과 환각률만 크게 하락, 변화는 "환각 꼬리"에 집중
- mean-median 격차 0.348 to 0.131

#### 3. 길이버킷별 환각률: 양자화 vs 구조 판정
![](https://velog.velcdn.com/images/xorms/post/95e98364-027e-4874-ae4f-d841052bff8c/image.png)
- E2B BF16 길이버킷 환각률: ~10 41.0% to 11~20 12.2% to 21~30 3.2% to ... to 101~ 0.0% (단조 감소)
- E4B NF4 대비(동일 버킷팅 재계산): ~10 68.6% to 41.0%, 11~20 43.4% to 12.2% 등 전 구간 하락하나 길이 의존성 구조는 양쪽 동일 보존
- 핵심: 양자화를 제거해도 짧은 발화 환각과 길이 의존성이 사라지지 않음, 양자화는 근본 원인 아님
- severity만 약 절반 완화 -> 환각률, CER 크기

즉, 양자화가 짧은 발화 환각률의 근본적 원인은 아니며 E4B NF4 → E2B BF16으로 바꿨더니 severity가 절반으로 줄었다.

단 그게 양자화 제거 덕인지, 모델이 작아져서인지는 아직 못 판단할 순 없다.
