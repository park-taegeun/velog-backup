이전에 알아봤던 것처럼 전체 구조는 이렇다.

```
오디오 → audio_tower(귀) → embed_audio(결합지점) → language_model(뇌) → 텍스트
```

- audio_tower = 소리에서 특징 뽑는 부분 (오디오 처리부)
- language_model = 텍스트 생성하는 부분 (글자 생성부)
- embed_audio = 둘의 결합 지점, **오디오 특징(1536 차원)을 LLM이 읽는 언어 차원(2560)으로 변환**하는 통로

간단하게 정리해보면,

풀려던 문제는 짧은 발화에서 모델이 오디오를 무시하고 말버릇으로 환각하는 현상이다.

베이즈 정리로 보면 ***전사문 = 가능도(오디오 증거) × 사전(언어 말버릇)*** 인데 오디오가 짧으면 가능도가 약해서 모델이 말버릇에 의존해서 지어냄

-> 그래서 결합 지점인 embed*audio를 강화해서 *약한 오디오라도 뇌가 무시 못 하게 전달을 세개 하는게_ 목표이다.

## 실험 결과

```
  정답(ref)     : Pearson +0.737  Speaㅠrman +0.775
  base        : Pearson +0.021  Spearman +0.374
  nb20 ft     : Pearson +0.755  Spearman +0.757
```

- 본 실험의 ft의 Pearson 상관은 0.755로 nb18 대비 약 6배 상승
- 대조군 base는 0.021로 오디오 길이를 거의 무시함

#### 길이 통제 실험 결과

```
과생성(정답 1.5배 초과) 비율: base 35.5% / nb20 ft 3.1%

길이 정상 케이스 168개 (과생성 제외):
  base_cer 평균: 0.3062
  ft_cer   평균: 0.2114
  (nb18에선 base 0.3013 < ft 0.5210 역전이었음)

전체 중앙값 CER: base 0.4530 / nb20 ft 0.1914
```

상관이 높다는 것은 "길이를 잘 맞춘다는 뜻일뿐 내용(전사 정확도)까지 좋아졌다는 말은 아님"

출력이 정답의 1.5배를 넘는 과생성 케이스를 양쪽 모두에서 제외한 뒤 base와 본 실험의 ft의 CER을 비교함

- 과생성(정답 1.5배 초과) 비율은 base 35.5%에서 nb20 ft 3.1%로 급감
- 길이통제 후 CER은 base 0.3062 > nb20 ft 0.2114로, nb20 ft가 base보다 약 31% 낮다
- 이전 실험에서 나타났던 역전(0.30 < 0.52)이 완전히 해소
- 전체 중앙값 CER도 base 0.4530에서 ft 0.1914로 절반 이하

방식은 4가지이다.

> 무작위 샘플: 랜덤 10개 ref/base/ft 비교
> ft가 정답 거의 맞춘 케이스(ft_cer 낮은 것): 성공 사례, 오디오를 제대로 들었나 확인
> base는 환각인데 ft는 고친 케이스(base_cer이 높고 ft_cer이 낮은 것): 통로 강화의 효과가 실제로 보이는 곳
> ft도 실패한 케이스(ft_cer 높은 것): 어떻게 실패하는지를 확인하기 위해서

#### 3. base 환각 -> 파인튜닝 성공

![](https://velog.velcdn.com/images/xorms/post/f8c35918-108f-445f-921e-67b91b8f2ff0/image.png)

- 대표적으로 "좋은 기회야"(6자) → base 72.33 (영화 예고편 내레이션 대본을 통째로 환각 창작) vs ft 0.17 "좋은 기회에"
- "특히 아프리카의 경우에" → base 3.33 "Okay, I'm ready. Please provide the audio"(영어 챗봇) vs ft 0.00
- "바이러스와 숙주 세포가 어떻게" → base 4.62 (정답에 없는 긴 설명문) vs ft 0.00.
- base의 실패는 "오디오를 안 들음"이고 ft는 "오디오를 들음"이라는 본질적 차이. 융합 통로 LoRA가 가능도 채널을 회복시켰다는 가장 직접적인 정성 증거

#### 4. 파인튜닝 실패 케이스

![](https://velog.velcdn.com/images/xorms/post/8e289fed-3179-4bac-bc3f-bdb80252e811/image.png)

- ft 실패 대부분이 발음 오인식. "또 거부하고" → ft "극복하고 싶다"(거부↔극복 발음 유사), "최민 씨" → ft "채미 씨"(발음 유사), "3년 이요" → ft "3년이요 3년이요"(내용 맞고 반복만)
- 잔존 환각은 극단 초단발화 2건뿐: "90"(2자) → ft 10.00, "네. 황 교수님"(8자) → ft 2.50으로 프롬프트 도피 잔존
