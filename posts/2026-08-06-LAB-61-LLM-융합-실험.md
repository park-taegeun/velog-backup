이전의 실험까지는 감정음성데이터셋을 사용하였다.

해당 데이터셋을 사용하여 두 경로(프롬프트 / 임베딩)를 통해 실험을 해보았지만 모두 어조 정보 음향 벡터가 감정 판단에 도움을 주지 않는다는 방향을 보았다.

그래서 곰곰히 생각을 해보았는데 결론은 이렇다.

```
낭독체에서 왜 안 됐을까?
- 감정 음성 데이터셋은 성우가 감정을 지정받아 낭독한 데이터
- 텍스트 내용과 지정 감정이 같은 방향으로 설계됨
- 텍스트-어조 불일치가 라벨로 존재하지 않음

성우가 "슬프게 읽어주세요"를 받고 읽은 문장은 텍스트도 슬프고 어조도 슬픔
즉, 텍스트만 봐도 알 수 있으니 어조를 더해도 얻을게 없고 오히려 노이즈가 되는 것
```

## 1. 데이터 전환

목적은 그대로다.

> 어조가 텍스트에 없는 정보를 전달하는가

위 목적을 가지고 데이터를 새로 찾았다.

### 데이터 선정 이유 )

#### 1. 감정을 4채널로 독립 태깅

- 텍스트 / 음성 / 이미지(표정) / 멀티모달 -> 텍스트 감정과 음성 감정을 서로 참조하지 않고 매김 -> 두 라벨이 어긋나는 발화 = 텍스트가 놓친 지점

#### 2. 화자 구조

- 배우 300명, 고정 2인 1조, 화자당 평균 284발화
- actor ID가 클립 경계를 넘어 유지 -> 화자별 z-score 가능

#### 3. 규모

- 6,000 클립
- 85,077 발화 -> 융합 학습 가능

### 데이터 실측 검증 )

#### 1. 불일치가 실제로 있는가

텍스트 감정 ≠ 음성 감정
5배치 (26,971 발화)를 다운받아 확인해보니 그 중 17,658건이 불일치가 존재하였고 이는 백분율로 65.5%이다.

텍스트가 neutral인 불일치가 전체 불일치의 41.8% = 대사는 아무 감정도 말하지 않는데 목소리가 감정을 싣는 경우로 해석이 가능하다.

```
대표 예시
- "진정하고 얘기 좀 해" -> 텍스트: neutral / 음성: angry
```

#### 2. 최종 판단은 어느 쪽에 가까운가

대사와 목소리의 감정 라벨이 어긋날 때 사람(라벨러)의 최종 판단(emotion.multimodal)은 대사보다 목소리에 6.9배 더 가까움

- 최종 판단 = 대사, 목소리, 표정을 모두 보고 매긴라벨

#### 3. 확보한 규모

- 5배치 2,000클립 / 26,971 발화 / 배우 100명
- 1.5초 이상 22,556 발화(전체 데이터셋의 33%)

비교) 이전 나독체 실험 -> 16,281 발화 / 화자 8명 -> 발화 1.4배, 화자 12.5배

## 2. 검증 설계

검증 설계에 두 가지 질문이 존재했다.

**1. 어조 벡터에 텍스트가 놓친 정보가 있는가 2. LLM이 그 정보를 판단에 활용하는가**

이 두 질문은 층위가 다르다 -> 정보가 있어도 전달되지 않을 수 있고 전달이 되어도 활용되지 않을 수 있음

그래서 단계도 두 단계로 나눴다.

#### 1단계: 선형 분류기

- 목적: 정보의 존재 확인
- 방법: 텍스트 임베딩 / 어조 벡터 / 둘의 결합 -> 세 조건으로 감정을 예측하고 정확도 비교

선형 분류기를 사용하는 이유는 모델 용량과 학습 방식의 영향을 최소화한 조건에서 어조가 텍스트 대비 증분을 주는지 먼저 확인

#### 2단계: LLM 융합

- 목적: 판단 기여 확인
- 방법: 63차 음향 정보 벡터를 gemma에 주입해 학습 (진짜 어조 vs 가짜 어조)

#### 공통 평가 설정

- 정답 라벨: 음성 감정 8종 (angry, contempt, dislike, fear, happy, neutral, sad, surprise)
- 화자 분리: 학습에 쓴 배우가 평가에 나오지 않음
- 어조 벡터: 63차에 화자별 z-score

## 3. 결과

### 1단계 - 선형 분류기

확률 = 분류기가 예측한 감정이 그 발화의 음성 감정 라벨과 일치한 비율

음성 감정 라벨을 정답으로 쓰는 이유

- 어조에는 정답 라벨이 없어서 감정을 대리 지표로 사용
- 그 중 음성 감정이 어조에 가장 가까운 라벨이기 때문

```
텍스트만 49.4% -> 30.7% (-18.7%p) 대사가 딴소리하니 무너짐
어조만 29.0% -> 30.3 (+1.3%p) 대사와 무관하게 일정
텍스트 + 어조 51.6% -> 34.1% (-17.6%p) 항상 텍스트 위

일치 구간: 텍스트가 어조를 20%p 앞섬
불일치 구간: 격차가 0.4%p로 사라짐

어조를 더하면 어느 구간에서도 텍스트보다 높고 텍스트가 무너지는 구간에서 증분이 더 큼
어조가 텍스트를 대체하는 것이 아님(전체로 보면 텍스트가 앞섬)
텍스트가 무너지는 자리를 어조가 받쳐주는 구조
```

### 2단계 - LLM 융합

#### 비교축 )

어조를 넣은 모델 vs 안 넣은 모델로 비교하면 학습효과와 어조 효과가 섞임 -> 어조를 넣은 쪽만 projection을 학습하기 때문

진짜 어조를 받은 모델 vs 짝이 어긋난 어조를 받은 모델

- 데이터, 학습량, seed, 하이퍼파라미터 모두 동일
- 다른 것은 각 발화에 들어간 벡터가 그 발화의 것인지 여부 하나

즉, 두 모델의 차이 = 어조 벡터의 순수 기여

#### 학습 )

- 학습 대상: projection 한 층 (63차 -> 2560차)
- gemma 본체는 전부 동결
- 학습 18,150 발화 (배우 80명) / 평가 4,406 발화 (배우 20명)
