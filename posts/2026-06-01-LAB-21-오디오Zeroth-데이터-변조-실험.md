기존 실험에서 Zeroth 데이터가 너무 깨끗해서 결과가 예상대로 나오지 않았다. 본 연구의 실제 환경은 회의실과 같은 노이즈가 있는 환경이기 때문에 오디오를 의도적으로 변환해보기로 했다.

## 변조 함수 설계

```python
SR = 16000

def perturb_silence(arr, start_sec, duration_sec):
    """지정 구간을 무음(0)으로 마스킹"""
    out = arr.copy()
    s = int(start_sec * SR)
    e = int((start_sec + duration_sec) * SR)
    out[s:e] = 0.0
    return out

def perturb_noise(arr, snr_db):
    """화이트노이즈를 SNR 기준으로 추가"""
    sig_power = np.mean(arr ** 2)
    noise_power = sig_power / (10 ** (snr_db / 10))
    noise = np.random.randn(len(arr)) * np.sqrt(noise_power)
    return (arr + noise).astype(np.float32)

def perturb_reverse(arr):
    """오디오 시간 반전"""
    return arr[::-1].copy()
```

변조 함수 3종: 중간 1초 무음 마스킹, 화이트 노이즈, 시간 반전

## 초기 결과

- **무음 마스킹**: LLM이 문맥으로 메우는데 완전히 틀린 단어보다는 문맥상 그럴듯한 단어로 채우는 경향
- **노이즈**: 세 샘플 모두 완전히 다른 문장 출력 → 음향 신호가 완전히 교란되면 LLM도 같이 무너짐 → 오디오 신호에 실제로 의존하고 있다는 증거
- **시간 반전**: 음성과 아예 무관한 내용 생성 → LLM이 그냥 그럴듯한 것을 만들어내는 것

## 무음 마스킹 격자 실험 (Silence Masking Grid)

위치(앞/중간/뒤) × 길이(0.5s/1s/2s) = 9개 조합을 N=100 샘플에 적용.

```python
mask_positions = ["front", "mid", "rear"]
mask_durations = [0.5, 1.0, 2.0]

rows = []
for i, (arr, ref) in enumerate(samples[:100]):
    for pos in mask_positions:
        for dur in mask_durations:
            start = get_mask_start(arr, pos, dur)
            perturbed = perturb_silence(arr, start, dur)
            hyp = transcribe(perturbed)
            sig = hallucination_signals(norm_for_cer(ref), norm_for_cer(hyp))
            sig.update(idx=i, position=pos, duration=dur, ref=ref, hyp=hyp)
            rows.append(sig)
```

### 결과

① **길이 효과**: 지울수록 비례해서 무너진다 (선형 상승) → 오디오 의존성 존재 확인

② **위치 효과**: rear가 압도적으로 견고하다
- front 1.0s: CER 0.158
- mid 1.0s: CER 0.235
- rear 1.0s: CER 0.104 ← baseline(0.089)이랑 거의 차이 없음
- 이유: 자기회귀(autoregressive) 디코딩 구조 — 앞부분 오디오를 정상적으로 들었으면 뒷부분이 무음이어도 앞 맥락 + 언어모델 사전 지식으로 커버

③ **del_rate vs ins_rate**: 무음엔 "대체"가 아니라 "삭제"로 반응
- ins_rate는 전 조합에서 0.012~0.018로 거의 불변
- del_rate는 0.018(rear 0.5s)에서 0.269(mid 2.0s)까지 15배 차이

④ **mid가 가장 치명적인 이유**: mid 2.0s CER=0.369. 앞뒤가 단절 → 구조적으로 취약한 위치

## SNR 곡선 실험

SNR(dB): 20, 15, 10, 5, 0, -5. N=100.

### 결과

① **CER 곡선 모양**: 선형이 아니라 가속 붕괴
- 20dB→15dB: 0.120→0.138 (0.018 증가)
- 15dB→10dB: 0.138→0.217 (0.079 증가)
- 10dB→5dB: 0.217→0.369 (0.152 증가)
- 5dB→0dB: 0.369→0.643 (0.274 증가)
- 0dB→-5dB: 0.643→0.876 (0.233 증가)

② **임계점: SNR 10dB 근방** — 그 이하부터 본격 붕괴

③ **ins_rate가 노이즈에서는 같이 오름**: 무음(건너뜀)과 노이즈(환각)가 오류 모드가 다름

## 시간 반전 실험

음향 에너지는 그대로 유지 + 언어 정보만 제거. 결과: CER > 1.0 → 모델이 원본보다 훨씬 긴 텍스트 생성 → LLM이 독립적으로 만들어낸 것이라는 증거.
