### [ 01. 데이터 프레임이란? ]

Pandas 라이브러리는 2차원 표를 다루는 라이브러리이다.

![](https://velog.velcdn.com/images/xorms/post/c573306e-1198-4ad4-abc0-cc4f7ec2f28f/image.png)

위 그림에서 보면 알 수 있듯이 왼쪽은 2차원 표(DataFrame), 오른쪽은 1차원 표(Series)이다.

2차원 표에서
- 행 왼쪽에 붙어있는 라벨: index
- 열 위쪽에 붙어있는 라벨: columns 라고 하며,

1차원 표인 Series에서는 columns는 없고 index만 존재한다.

### [ 03. boolean indexing ]

boolean indexing은 True, False의 bool 자료형으로 하는 인덱싱이다.

- 라벨 이름을 리스트로 묶어서 인덱싱을 하는 것이 아닌 행/열의 개수와 똑같은 개수를 가진 배열을 생성
  → 갖고 오려는 행/열 라벨을 TRUE, 버리려는 행 라벨을 FALSE

그렇다면 왜 Pandas에서 boolean indexing이 좋냐?

- 대소 비교를 통해서 boolean 배열을 너무 쉽게 가져올 수 있음

```python
# ex..
df["수학"] > 90
# → [False, True, False, True] 같은 배열이 생성

s1 = df["수학"] > 90
df.loc[s1]   # boolean indexing
```
