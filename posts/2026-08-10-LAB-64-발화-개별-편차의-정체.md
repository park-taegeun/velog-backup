## 실험 흐름 정리

세 단계로 쪼개서 보고 있었다.

1. 오디오에 텍스트에 없는 정보가 있는가
2. 그 정보가 gemma까지 전달되는가
3. gemma가 그 정보를 쓰는가

- ① - 이전 랩미팅에서 오디오에 텍스트에 없는 정보를 확인
- ② - 소프트 토큰 확장 실험에서 통로를 4배 넓혔더니 두 성분이 각각 2.0배, 2.9배로 커졌다 → 정보가 더 진하게 흐름

### ③에서 뭘 봤나 (성분 분해 결과)

여기서 이상한 점이, 개별 성분이 더 정확한 정보인데 방해가 된다.

왜 이상한가. real과 plac은 둘 다 벡터를 받음. 차이는 그 발화만의 편차(δ)가 자기 것이냐 남의 것이냐다.

```
63차 = (감정 수준 정보) + (그 발화만의 편차 δ)
       ↑ real, plac 동일        ↑ 여기만 다름
```

여기서 δ가 그냥 잡음이라면 real이나 plac이나 쓸모없는 걸 하나씩 받는 셈이니 비슷해야 함. 하지만 real 모델이 점수가 더 떨어짐.

이유가 두 가지 있을 수 있음.

**[ δ는 잡음이다 ]**
- 화자 신원은 층2 z-score로 이미 제거됨 (신원 프로브 0.958 → 0.026)
- 그래도 남는 것: 발화 길이, 음소 구성
  - 63차 중 52차가 MFCC 계열 (평균 26 + delta 26)
  - MFCC는 원래 "무슨 소리를 냈는가"를 기술하는 물건
  - "아"와 "이"는 어조와 무관하게 MFCC가 다름
- 이 경우 모델이 규칙성은 배우지만 감정과 무관

**[ δ는 정보인데 채점축이 다름 ]**
- δ가 담고 있는 게 "같은 ANGRY 안에서도 진심인가 억지인가", "상대를 향한 태도" 같은 것이라면, 감정 8종 맞히기에는 도움이 안 된다 → 어차피 다 ANGRY로 찍으면 되니까
- 그런데 이게 연구 목적 그 자체 — 비꼼, 강요된 동의, 억눌린 반대 전부 같은 감정 라벨 안에서 갈리는 것들

### 지금은 왜 구분이 되지 않는가

두 해석이 똑같은 결과를 낸다. 잡음이어도 real이 떨어지고, 다른 축 정보여도 real이 떨어짐. 지금 가진 숫자는 전부 `sound.emotion` 정답률 뿐이라 잣대가 하나뿐이고, 두 경우가 겹쳐 보인다.

## 그래서 이번 실험

**하는 일**: δ를 계산해서 떼어내고, 여러 정답지를 번갈아 대본다.

```
δ = 자기 발화 벡터 − 같은 감정 발화들의 평균
```

### 0. 먼저 δ가 뭐였는지

63차 벡터(층2)에서 그 감정의 평균을 뺀 나머지.

```
ANGRY 발화의 벡터 − ANGRY 발화들의 평균 = δ
```

즉, "화났다"는 공통분은 사라지고 "이 발화만 달랐던 부분"만 남음.

### 1. 검산

8개 정답지 중 두 개는 안 나와야 정상인 항목.

**[ 정답지1: 소리 감정 ]** — δ = 감정 평균을 뺀 값이므로 감정 정보는 이미 빠져나감. 여기서 감정이 맞혀지면 뺄셈이 잘못된 것.

```
원본 L2 :  정답률 0.2960   기준선 0.2056   차이 +0.0903
δ       :  정답률 0.2056   기준선 0.2056   차이 +0.0000
```

기준선(발화를 아예 안 보고 제일 흔한 감정 DISLIKE만 계속 찍었을 때) = 20.56%. δ의 점수가 소수점 넷째 자리까지 똑같음. 원본 벡터는 기준선보다 9%p 높았는데 그게 δ에서는 0 → 감정 정보는 100% 감정 평균 쪽에 있었고 δ에는 넘어오지 않음.

**[ 정답지2: 화자 ]** — 층2 설계 자체가 화자를 지우려고 만든 것(화자별 z-score).

```
원본 L2 :  정답률 0.0027   기준선 0.0126   차이 -0.0100
δ       :  정답률 0.0044   기준선 0.0126   차이 -0.0082
```

둘 다 기준선 이하 → 층2 정규화가 제대로 작동 중.

### 2. 3, 4, 5번 정답지

δ한테 세 가지(감정과 무관한 것들)를 맞혀보라고 시켰다. 이런 것들을 맞추면 δ 안에 감정과 무관한 게 섞여 있다는 뜻. 감정 평균을 뺐는데 거의 하나도 안 줄음.

## 정리 (근거)

**[근거 1] 델타의 최대 성분은 말하기 속도이며, 이것은 어조다**
- 말하기 속도(초/글자) R² 0.310. 8개 프로브 중 최대
- 글자 수를 뺄셈으로 통제한 길이 잔차에서도 0.243으로 재현 (나눗셈/뺄셈 두 경로에서 같은 결론)
- 화자 z-score 후이므로 "그 화자 평소 대비 이번엔 얼마나 빨랐나" → 연구의 어조 정의와 정확히 일치

**[근거 2] 그런데 이 성분은 소리 감정을 전혀 예측하지 못한다**
- 속도만으로 소리 감정 예측: +0.0005 (기준선과 동일)
- 감정별 평균 속도: ANGRY 0.189 ~ SURPRISE 0.208, 차이가 0.02초/글자로 실질적 동일
- 즉 real 조건은 정확한 어조 정보를 받았으나 그 정보가 채점 축과 직교했다

**[근거 3] 감정 계열 라벨 전반에서 동일하다**
- 델타로 영상 포함 감정 예측: +0.0079 (원본 L2 +0.0717에서 89% 감소)
- 델타로 텍스트 감정 예측: +0.0011 (원본 +0.0084에서 87% 감소)
- 감정 정보는 라벨 종류를 불문하고 감정 수준 성분 쪽에 몰려 있음

**[부산물 1] 채점표 전환만으로는 해결되지 않는다** — 채점 라벨을 `mm_emotion`으로 바꿔도 델타는 +0.0079로 거의 무정보. 학습 3회(7.5시간) 이전에 확인됨.

**[부산물 2] 델타에 텍스트-음성 불일치 신호가 독립적으로 존재한다**
- AUC 0.5364, 95% 신뢰구간 [0.5191, 0.5545]
- 원본 L2(0.5166)보다 높음 → 감정 평균이 이 신호를 희석하고 있었음
- 속도/길이/글자수/모음 성분을 모두 회귀로 제거해도 0.5356으로 유지 → 다른 어떤 성분과도 겹치지 않는 독립 성분
- 델타에서 감정 축에 걸리는 유일한 성분

**[부산물 3] 대본 성분이 섞여 있다**
- 글자 수 R² 0.127, 모음 구성 R² 0.098
- 화자가 어떻게 말하든 바뀌지 않는 값이므로 어조가 아님
- 63차의 83%(52차)가 MFCC 계열이며, MFCC는 본래 발음을 기술하는 특징
- 기존 잔차 분석에 쓴 임베딩 3종은 모두 의미 임베딩이라 발음을 담지 않음 → "텍스트가 설명 못 하는 90%"에 이 성분이 그대로 남아 있었음

### [델타의 구성 - 세 성분이 서로 독립]

| 성분 | 지표 | 성격 |
| --- | --- | --- |
| 말하기 속도 | R² 0.310 | 어조. 감정 예측 못 함 |
| 대본 성분 | R² 0.098~0.127 | 어조 아님 |
| 불일치 신호 | AUC 0.5364 | 어조 축. 가장 작음 |

## 해석

- real 조건의 하락은 정보가 부정확해서가 아니라, 정확한 어조 정보가 현재 채점 축과 직교하기 때문일 가능성이 높다
- k=4에서 개별 성분이 -0.99에서 -2.84로 악화된 것도 같은 그림 — 통로를 넓히면 감정 축과 무관한 정보가 더 진하게 흘러 들어간다
- 어조 모듈은 감정 분류기가 아니라 정보 제공자라는 연구 전제와 방향이 일치한다
- 감정 8종으로 환원되지 않는 어조 정보의 존재를 직접 측정으로 확인했다

## 한계

- 델타에 무엇이 있는지 확인한 것이며, gemma가 이를 실제로 참조했는지는 미확인
- 원인으로 확정하려면 특정 성분을 제거한 벡터로 재학습이 필요
- 말하기 속도가 비꼼이나 강요된 동의를 포착한다는 증거는 없음 (속도만으로 불일치 예측 시 AUC 0.4930으로 무정보)
- 불일치 신호는 존재하나 AUC 0.5364로 약함
- 불일치 여부는 결국 라벨 두 개를 비교한 값이므로 완전한 라벨 독립 측정은 아님
