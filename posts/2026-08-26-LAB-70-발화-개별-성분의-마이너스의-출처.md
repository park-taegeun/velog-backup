이전 실험까지 real − plac인 발화 개별 성분은 계속 음수인 상태이다.

평가 발화인 4,406 발화를 real과 plac의 채점 결과로 세 분류로 나누어보았다.

- real만 맞힌 발화
- plac만 맞힌 발화
- 두 조건이 같은 결과인 발화

```
[ 평가 발화 4,406 -> 세 분류로 나눈 결과 ]
real만 맞힘     502개
plac만 맞힘     544개
둘 다 같은 결과 3,360개
```

즉, −0.95라는 숫자는 502대 544에서 나온 것

- 502개 = 진짜 소리를 줘서 맞힌 발화
- 544개 = 진짜 소리를 줘서 틀린 발화

위 결과의 상황은 진짜 소리를 주면 오히려 못 맞히는 일이 더 많다.
근데 왜 인지 모르는 상황임.

## 논리로 풀어보면

544개는 진짜 소리 때문에 틀린 발화 -> 이 발화들의 어떤 공통점때문에 발생한 일이 아닐까??

예를 들어서 만약 544개는 대부분 짧은 발화였다.
그러면 왜 발화 개별 정보가 음수냐에 대한 답이 될 수 있음.

그래서 다섯 방향을 확인해봄

- 층2 편차 크기 -> 평소랑 많이 다른 발화라서 그런가?
- 감정 분포 -> 특정 감정에서만 그런가?
- 발화 길이 -> 짧아서 그런가?
- 텍스트 확신도 -> 대사가 뚜렷해서 그런가?
- 라벨 일치 -> 대사가 딴소리해서 그런가?

## 결과

- 가로축: p값이며 각 성질에서 두 발화군이 얼마나 다른지를 나타내는 수치 (값이 작을수록 두 집단이 다름)
- 붉은 점선: 판정 기준선 0.05 = 이 선보다 왼쪽에 있으면 그 차이가 우연으로 설명되지 않음

다섯 성질 중에서 '텍스트 확신도'와 '라벨 일치 여부' 두 가지에서 발화군이 갈림

### 라벨 일치 여부

진짜 소리가 도움이 된 발화는 라벨이 일치하는 쪽에 상대적으로 더 많음

```
평가 발화 = 4,406 발화
- 대사≠목소리 (불일치) 2,816개 = 63.9%
- 대사=목소리 (일치)   1,590개 = 36.1%
-> 원래부터 불일치가 훨씬 많음
```

그 중에서 진짜 소리(real) 덕분에 맞힌 발화 502개

- 불일치 295개 (58.8%)
- 일치 207개 (41.2%)
- -> 여기도 불일치가 더 많음

이번엔 진짜 소리가 못 맞힌 544개

- 불일치 358개 (65.8%)
- 일치 186개 (34.2%)

그래서 위 세 경우를 놓고 보면

- 전체: 불일치 63.9%
- 502개(도움): 불일치 58.8% ← 조금 적네
- 544개(방해): 불일치 65.8% ← 조금 많네

셋 다 불일치가 과반인데 502개만 살짝 덜함 -> 이게 전부

그래서 뭘 말할 수 있냐 = "도움받은 발화는 방해받은 발화보다 라벨 일치의 비중이 조금 크다"
하지만 도움이 된 발화에서도 불일치가 과반임

### 텍스트 확신도

대사만 보고 감정을 얼마나 자신 있게 맞힐 수 있는지 점수, 0~1 사이 값

- 점수 높음 = 대사만 봐도 감정이 뚜렷함
- 점수 낮음 = 대사만으로는 애매함

두 무더기의 평균

- 502개 (real만 맞힘) -> 평균 0.533
- 544개 (plac만 맞힘) -> 평균 0.556

라벨과의 다른 점은 라벨은 '불일치냐 일치냐' -> 둘 중 하나,
확신도 -> 연속값이기 때문에 평균으로 비교함

- real만 맞힌 502개의 확신도는 0.533으로 plac만 맞힌 발화의 확신도보다 상대적으로 낮기 때문에 대사가 더 애매한 쪽
- plac만 맞힌 544개의 확신도는 0.556으로 real만 맞힌 발화의 확신도보다 상대적으로 높기 때문에 대사가 좀 더 뚜렷한 쪽

근데 차이가 작음

## 종합

결과를 종합해보면 진짜 발화 개별 정보에 도움을 받은 발화(real만 맞힌 발화)는 라벨은 일치 비중이 조금 큰 쪽 + 확신도는 낮은 쪽

- 라벨 일치 = 대사 감정과 목소리 감정이 같은가
- 확신도 = 대사만 보고 자신있게 고를 수 있는가
