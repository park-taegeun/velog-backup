### [ 1.  Transformer ]

첫 개념은 Transformer이다.
AI를 간접적으로 접해본 사람들도 많이 들어봤을 이름이라고 생각될만큼 NLP 쪽에서는 확실한 자리를 잡고 있다.

여기서 NLP란 Natural Language Processing이며 "자연어 처리"를 뜻한다.
즉, 컴퓨터가 인간의 언어를 이해하고 처리할 수 있도록 하는 것을 의미한다.

현재 Transformer가 모든 NLP의 뿌리로 자리매김을 했는데 지금부터 그 과정에 대해서 알아보자!!

NLP의 발전 과정)
1세대: RNN "단어를 하나씩 순서대로 읽음"
2세대: LSTM "긴 문장도 읽으려고 노력함"
3세대: Transformer "문장 전체를 보고 관계를 파악함"

간단히 보면 위와 같다.

RNN의 한계점부터 알아가보자면,

- 우선 RNN은 사람이 책을 읽듯이 단어를 하나씩 순서대로 학습하는 모델이다.
- 장기 의존성 손실: 긴 문장에서 앞부분 기억이 사라짐
- 병렬 처리 불가: 단어를 순서대로 읽어햐 해서 GPU 활용 어려움 -> 학습 속도 느림
- 양방향 정보 손실: 단어의 의미를 파악하기 위해서는 앞, 뒤 단어 모두 봐야하는데 RNN은 앞만 본다.

그래서 이러한 문제를 해결하기 위해 RNN에 "기억할 것/잊을 것"을 결정하는 게이트를 추가한 것이 LSTM이다.

이 LSTM은 RNN의 장기 의존성 손실 문제는 어느정도 해결했지만 여전히 병렬 처리가 아닌 순차 처리 방식이라 학습 속도가 느리고 매우 긴 문맥에는 한계점을 보인다.

이러한 과정 속에 등장한 모델 아키텍쳐가 **"Transformer"**이다.
2017년, 구글 논문 'Attention Is All You Need'가 등장하면서 NLP는 완전히 바뀌게 되었다.

Transformer의 원리를 간단히 한 줄로 설명해보면

> ***순서대로 읽지 말고, 문장 전체를 한꺼번에 펼쳐놓고 단어들끼리의 관계를 직접 계산하자.***

```
RNN/LSTM 방식: "나는" → "학교에" → "갔다" (순차)

Transformer 방식:
        ┌─────────────────┐
        │ 나는  학교에  갔다  │
        └─────────────────┘
            ↕    ↕    ↕
        모든 단어가 서로를 동시에 봄

-> 이것을 가능하게 한 핵심 메커니즘 "attention"
```

- 병렬 처리 가능 -> GPU 활용하여 학습 속도 상승
- 긴 문맥 처리 가능
- 모델 크게 만들수록 성능이 좋아짐 -> 확장성 좋음(스케일링 법칙)

---

다음으로, 관련 모델들과 용어들을 간단히 알아보고 글을 마무리 할 것이다.

#### [ Attention ]

단어 하나가 모든 단어를 둘러보고 누구한테 더 주목해야하는지 점수 매기는 것을 의미한다.
1. Self-Attention: 한 문장 안에서 단어들끼리 서로 봄
2. Multi-Head Attention: 여러 관점으로 동시에 봄
3. Positional Encoding: 순서 정보 추가
4. Feed-Forward Network: 각 단어를 한 번 더 변환

#### [ LLaMA-3 ]
- Meta가 만든 오픈 소스 LLM(대규모 언어 모델)
- Transformer 기반 (Decoder 위주)

#### [ LoRA ]
- 거대 모델을 효율적으로 파인튜닝하는 기술
- 거대 모델 전체를 학습하는 건 GPU 부담 너무 큼
- LoRA는 모델 본체는 그대로 두고 작은 어댑터만 학습

#### [ Decoder ]
- 일반 컴퓨터 맥락에서는 압축 및 암호화 풀기, 데이터 형식 변환 등 코드를 분해해서 정보를 표현하는 것을 의미
- 입력을 받아서 출력을 한 단어씩 생성하는 모듈
- 한 단어씩 차례차례(단방향) 보고 다음을 예측함

#### [ Encoder ]
- 입력을 이해하는 모듈
- 입력을 한 번에 전체 보고 각 단어(벡터)의 의미를 찾아냄 -> 관계를 통해서
