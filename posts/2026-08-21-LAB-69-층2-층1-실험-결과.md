이전 기록에서 설계한 대로, projection을 126차원을 입력 받을 수 있게 학습을 진행하였다.

그 후, real / plac / plac_cross 세 가지 경우로 8종 감정 맞추기 테스트를 진행하여 결과를 보았다.

결과를 보면, 같은 감정 남의 발화(plac) 목소리를 준 경우가 진짜 목소리를 준 경우보다 잘 맞혔다.

## 세 점수로 두 성분을 추출

### 감정 수준 성분

감정 수준 성분 = plac − plac_cross = 40.69 − 37.63 = **+3.06%p**

즉, 감정 정보가 판단에 도움이 되는 것은 확실

### 발화 개별 성분

발화 개별 성분 = real − plac = 39.74 − 40.69 = **−0.95%p**

- 둘의 차이는 그 소리가 이 발화 본인 것이냐, 남의 것이냐
- 즉, 짝이 맞는 소리를 주는 것의 값어치
- p=0.204904 -> 5분의 1 확률로 운으로도 나올 수 있는 차이
- 따라서 이 마이너스 값이 진짜인지 우연인지 판별이 안 되는 상태

### 합계

합계 = real − plac_cross = 39.74 − 37.63 = **+2.11%p**

```
(plac − plac_cross) + (real − plac) = real − plac_cross
   +3.06        +      (−0.95)      =    +2.11
```

p=0.002152 -> 우연의 범위가 아님

즉, 어조 정보가 판단에 기여함
-> 층1을 함께 넘긴 것이 그 차이를 만든 것

## 일치 / 불일치 구간 분석

대사만 읽고 매긴 감정인 text_emotion과 목소리만 듣고 매긴 감정인 sound_emotion,
이 두 가지 감정이 같을 수도 있고 다를 수도 있음

```
전체 22,556발화
  ├─ train  18,150   ← 학습용
  └─ test    4,406   ← 채점용, 평가 화자 20명
```

불일치 = 대사만 보면 틀리는 문제 -> 비꼼이나 억눌린 감정 같은 것

감정 수준 성분을 두 구간(일치 / 불일치)에서 따로 재봄.
구간별로 나눠서 보는 이유는 어조 정보가 어떤 상황에서 도움이 되는가를 알고 싶어서.

결과

- 불일치 +5.43 (p<0.000001) ← 여기서 작동
- 일치 −1.13 (p=0.355) ← 0과 구분 안 됨

즉, 대사가 딴소리할 때 소리 정보가 답을 살리는 방향

## 어조 정보 작동 구간이 세 번 흔들림

감정 수준 성분을 두 구간(텍스트-음성 일치/불일치)에서 따로 잰 값

- 화자평균 층2: 불일치에서만 작동, 일치는 0과 구분 안 됨 -> "어조는 텍스트가 무너지는 자리에서만 작동함"
- 감정균등 층2: 일치 쪽이 더 커짐, 불일치는 줄어듦 -> 이전 서사가 성립하지 않음
- 층1 결합: 다시 뒤집힘, 불일치 +5.43 -> 원래 서사로 돌아왔고 더 강해짐

즉, 층2 벡터를 어떻게 만드느냐에 따라, 어조 정보가 도움이 되는 상황이 매번 달라졌다.
어떤 설계에서는 대사가 딴소리하는 발화에서만 도움이 됐고, 어떤 설계에서는 대사가 정답을 가리키는 발화에서 더 도움이 됐다.

왜 이렇게 달라지는지는 확인하지 못했다.
