## 다음 작업 방향성
### 1. Gemma가 실제로 뱉는 것
gemma한테 "이 발화의 감정은?" 이라고 물으면 겉으로는 ANGRY 하나를 답함
하지만 속으로는 8개 전부에 점수를 매김
```
ANGRY    0.31
DISLIKE  0.29
SAD      0.18
HAPPY    0.11
NEUTRAL  0.06
FEAR     0.03
SURPRISE 0.01
CONTEMPT 0.01

여기서 제일 높은 것을 답으로 내놓는 것
```

### 2. 현재 채점 방식이 버리는 것
정답이 ANGRY라고 하면 지금 방식은 1등이 ANGRY냐만 확인함
-> 맞으면 1점, 틀리면 0점

```
그런데 이런 경우도 존재함
경우 A:  ANGRY 0.31,  DISLIKE 0.29   ← 아슬아슬하게 맞힘
경우 B:  ANGRY 0.95,  DISLIKE 0.02   ← 확실하게 맞힘
```

위 경우로는 지금 채점 방식으로는 둘 다 똑같이 1점
즉, 정답률은 문턱을 넘었냐만 확인하지 얼마나 여유 있게 넘었는지는 버림

### 3. 그래서 뭘로 바꾸나
**정답에 확률을 얼마나 줬나**를 그대로 점수로 사용함
- 경우 A: 0.31
- 경우 B: 0.95
-> B가 더 잘한 것임

정확히는 위 확률에 로그를 씌어서 사용함 -> 그러면 비트(bit) 단위가 나옴 = 정보량의 단위

로그를 왜 씌우냐면 그래야 **정보를 얼마나 줬나**로 해석되기 때문임
확률 그대로면 그냥 숫자인데 로그를 씌우면 정보이론의 언어가 되는 것

### 4. 그래서 결과가 어떻게 바뀌나

#### 지금 결과 문장
> 어조 벡터를 주면 감정 정답률이 2.11%p 오른다

#### 바뀌는 결과 문장
> 어조 벡터가 텍스트 위에 정보를 X비트 얹는다

과제 명세의 어조를 분석해서 융합단에 넘기는 정보 제공자의 역할에 더 적합하다고 판단

### 5. 구간 나누는 축도 문제가 있었음
지금까지 구간을 나누던 축은 text_ne_sound 하나뿐
-> 대사 감정 라벨과 소리 감정 라벨의 이름이 같은지 다른지만 보는 이진값

이 축은 정도를 구분하지 못함
```
발화 A:  대사 happy,  소리 surprise   ← 거의 비슷한 감정
발화 B:  대사 happy,  소리 angry      ← 정반대
```

둘 다 "불일치"로 묶임
연구가 찾는 비꼼은 B인데 A랑 섞여 있음

### 6. 사용하지 않은 값이 있었음
지금까지 사용하지 않은 **text_val(대사만 읽고 매긴 긍정도)** 과 **sound_val(목소리만 듣고 매긴 긍정도)**를 사용함
```
1점 = 완전 부정
10점 = 완전 긍정
```

이 둘의 차이를 구하면 어긋난 방향과 크기가 숫자로 나옴
```
발화 A:  대사 7,  소리 6   →  +1  (거의 같음)
발화 B:  대사 8,  소리 2   →  +6  (크게 어긋남)
```

차이의 부호가 성격을 가름
#### 대사는 긍정인데 소리는 부정 (큰 양수)
```
"아 진짜 잘했네요"를 비꼬는 투로
"괜찮아"를 힘없는 목소리로
```
Masking: 비꼼, 억눌린 감정 등

#### 대사는 부정인데 소리는 긍정 (큰 음수)
```
"아 짜증나"를 웃으면서
```
Coping: 힘든 걸 밝게 넘기는 것

#### 둘이 비슷함
```
"기뻐"를 기쁜 목소리로
```
Congruent: 평범한 경우

---

그래서 다음 작업으로는 크게 1~4번(정답률 -> 정보량)과 5~6번(감정가 축) 이렇게 두 가지 방향성을 가지고 할 계획이다.
