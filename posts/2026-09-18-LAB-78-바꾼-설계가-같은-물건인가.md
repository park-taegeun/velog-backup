## 무엇이 문제인가

실전 모듈의 층2는 실험과 다르게 만들어짐

| | 실험용 | 실전용 |
|---|---|---|
| 기준점 | 감정균등 | 화자평균 |
| 표준편차 | 화자별 | 전역 |
| 기준점 표본 | 250발화 | 4~7발화 |
| 표준화 통계 | 학습 split | 전체 21,564 |

각각은 근거가 있는 결정이지만 **세 가지가 겹치면 결과물이 얼마나 달라지는지 알 수 없음**

특히 지금까지 보고한 수치
- Masking 구간의 순효과가 전체 평균의 세 배

이것은 실험용 층2에서 나온 것
실전 모듈이 같은 기여를 내는지 확인되지 않은 상태

확인하려면 채점이 필요한데 체크포인트가 소실되어 불가능함

## 채점 없이 무엇을 할 수 있나

채점은 못 하지만 **벡터끼리 비교하는 것은 계산만으로 가능함**

```
같은 발화 21,564개에 대해

실험용 층2 만들기  →  63차 벡터
실전용 층2 만들기  →  63차 벡터
                   ↓
                얼마나 닮았나?
```

두 갈래의 결과를 예상)
- 많이 닮았다 -> 성능도 비슷할 것이라 말할 근거가 됨
- 별로 안 닮았다 -> 기존 수치를 그대로 가져다 쓸 수 없다는 것이 드러남

**어느 쪽이든 지금의 "모릅니다"보다는 나음**

특히 Masking 구간에서만 크게 갈리는지를 확인해야 함
그 구간이 이 연구의 핵심 발견이므로 거기서 무너지면 실전 전환의 의미가 크게 줄어듦

## 측정 방식

- 실험용은 기존 방식대로 화자별 감정균등 평균과 감정별 분산의 평균으로 생성
- 실전용은 모듈과 같은 방식으로, 대화 안에서 이전 발화만 평균 내고 전역 표준편차를 쓰며 이전 발화 4개 미만이면 층2가 없음
- 실전용 층2가 켜진 8,772발화만 비교 대상 (꺼진 발화는 실전용이 0이므로 비교가 성립하지 않음)
- 발화마다 두 벡터가 같은 방향을 가리키는지를 코사인 유사도로 측정
- 63개 성분 각각이 함께 움직이는지를 피어슨 상관으로 측정

## 전체 결과

**발화별 코사인 유사도**
```
평균 0.824 / 중앙 0.857
0.5 미만 2.7%
```

**차원별 피어슨 상관**
```
평균 0.860 / 최소 0.763
0.7 미만인 차원 0개
```

읽는 것)
- 대체로 같은 방향을 가리키되 동일하다고 볼 수준은 아님
- 63차 전체가 고르게 조금씩 다름. 특정 성분만 붕괴한 것이 아님

## 구간별 결과

| 구간 | 코사인 |
|---|---|
| Masking | 0.823 |
| Congruent | 0.822 |
| Coping | 0.828 |

세 구간이 소수점 셋째 자리에서만 갈림

-> 설계 전환의 영향이 특정 구간을 골라 때리지 않음
-> **핵심 발견인 Masking 구간이 선택적으로 훼손될 근거는 확인되지 않음**

## 어디서 갈리는가

평균 0.824만으로는 불일치의 성격을 알 수 없음
코사인 하위 5%와 상위 5%를 갈라 두 집단을 비교

| | 갈린 발화 | 닮은 발화 |
|---|---|---|
| **층2 크기** | **6.5** | **15.1** |
| 대화 내 순번 | 5번째 | 7번째 |
| 구간 쏠림 | 없음 | 없음 |

두 집단을 가르는 것은 **층2의 크기**였음

> 층2 크기 = 그 발화가 평소에서 얼마나 벗어났는지

![](https://velog.velcdn.com/images/xorms/post/2878e9a8-d44a-49e7-a019-459038c93a2b/image.png)


층2 크기 10% 구간별 코사인 중앙값
```
가장 작은 구간   0.73
가장 큰 구간     0.94
```

읽는 것)
- 붉은 선이 왼쪽에서 낮고 오른쪽으로 갈수록 올라감
- 점 구름이 왼쪽에서 아래로 넓게 퍼지다가 오른쪽에서 좁아짐

## 이 결과를 어떻게 읽어야 하는가

편차가 작은 발화에서 방향이 흔들리는 것은 구조적임
벡터의 크기가 작으면 작은 차이가 각도를 크게 바꿈

나침반으로 치면
- 자기장이 강하면 바늘이 확실히 북쪽을 가리킴
- 약하면 바늘이 흔들림

그런데 **이 연구가 잡으려는 것은 평소와 다르게 말한 발화**
그런 발화는 층2 크기가 크고, 거기서 두 방식은 0.94로 일치함

따라서 불일치는 어조 정보가 실릴 만한 발화가 아니라 그렇지 않은 발화에 몰려 있음

기준점 표본 수도 같은 방향을 가리킴
갈린 발화는 대화의 다섯 번째, 닮은 발화는 일곱 번째
기준점이 적은 표본으로 만들어졌을수록 갈림

## 결론

실전 모듈은 실험과 네 군데가 다르게 만들어졌다
그것이 같은 물건인지 확인하려면 채점이 필요한데 계산 자원이 없어 불가능하다

그래서 채점 대신 벡터를 비교했다
코사인 유사도 평균 0.824
대체로 같은 방향이지만 동일하다고 볼 수준은 아니다

그런데 평균값보다 중요한 것이 따로 있었다
불일치가 고르게 퍼져 있지 않다는 것이다

층2 크기가 작은 발화, 즉 평소대로 말한 발화에서 갈리고
평소에서 크게 벗어난 발화에서는 0.94로 일치한다

이 연구가 잡으려는 것은 후자다
비꼼, 억눌린 감정 같은 것은 모두 평소에서 벗어난 발화다
거기서는 두 방식이 같은 값을 낸다

구간별로도 갈리지 않는다
Masking, Congruent, Coping이 소수점 셋째 자리에서만 다르다
핵심 발견이 선택적으로 훼손될 근거는 없다

다만 벡터가 닮았다는 것이 성능이 같다는 뜻은 아니다
0.824가 융합단의 판단에 어떻게 반영되는지는 채점으로만 알 수 있다

이 자료가 보이는 것은 손실이 있다면 어느 발화에 몰릴지까지다

지금까지 "모릅니다"였던 것이 "얼마나 다른지는 압니다"가 되었다
그것이 이번 측정의 성과다
