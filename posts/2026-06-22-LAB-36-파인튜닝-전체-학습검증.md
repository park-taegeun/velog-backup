이전 소규모 학습을 통해 파이프라인 및 방향성을 검증하였다.

본 실험에서는 전체 데이터를 학습할 것이다.

```
전체 풀 3588
├─ test  828   (홀드아웃 — 학습에 절대 안 씀, 최종 평가용)
└─ train+val 2760
       ├─ val   275   (학습에 안 씀, 매 epoch 후 "잘 되고 있나" 확인용)
       └─ train 2485  
```

위 데이터 구조도에서 이전의 소규모 학습은 2485개 중에서 480개만 랜덤으로 뽑아서 파이프라인 검증용으로 먼저 돌린 것이고, 이제 2485 전체를 학습으로 다 사용할 것이다.

2485개로 학습 중에 매 epoch 끝난 후 확인용으로 val 검증 데이터를 사용한다.

---

## 1. 학습 과정

![](https://velog.velcdn.com/images/xorms/post/5b3e86ac-f904-427b-a32e-dcf55d946080/image.png)
위 학습에서 알 수 있는 것은

- val loss가 모든 구간에서 이전 소규모 학습보다 낫다
-> 대규모 학습 best 3.419 vs 소규모 학습 best 3.673
-> 데이터 5배로 학습이 더 잘 됨
- 단, loss 개선이 핵심 지표인 audio-gap으로 이어지는지는 4-way CER 평가로 별도 확인 필요

## 2. 4-way CER 평가

![](https://velog.velcdn.com/images/xorms/post/b5e21c35-b5ed-4291-842e-5110fef53d13/image.png)
![](https://velog.velcdn.com/images/xorms/post/1e81660b-392b-4b24-8f8f-d4e2b8e3f83c/image.png)
소규모학습(stage 1 - 480샘플)과 전체학습(stage 2 - 2485 샘플) QLoRA 파인튜닝 결과를 동일 test 셋(828, 안 본 화자)에서 4-way CER로 비교

### 결과 해석

#### base 재현성 확인

- stage1/stage2 base 수치 완전 동일 (short -0.1160, long 0.6549)
-> 같은 NF4 모델, 재현성 확인

#### 핵심 성과

- 짧은 발화에서 audio-gap: base -0.1160 → stage1 ft 0.2725 → stage2 ft 0.3348
-> 데이터 증량으로 짧은 발화 개선이 더 강화됨
-> 파인튜닝이 짧은 발화의 오디오 의존도를 높인다는 가설 확인

#### 부작용

- stage2 finetuned long: cer_silence 1.9415, audio_gap 1.3394
-> stage1 ft: cer_silence 0.8879, audio_gap 0.4010 대비 폭증

![](https://velog.velcdn.com/images/xorms/post/175bafbe-9596-4db9-9353-2cfd0183d4f6/image.png)

- 무음 입력 시,
->  "그렇죠. 그게 바로 그게 바로..." 반복 루프,
-> "그렇다면 그게 우리 사회에 어떤 영향을 미칠까요?" 상투어 생성
-> KconfSpeech 대화체 패턴 과학습으로 추정

#### 결론

```
[ 확인된 것(성과) ]
- base 모델은 짧은 발화(≤30자)에서 오디오를 무시하고 환각을 생성함 → audio-gap 음수(-0.1160)로 확인
- QLoRA 파인튜닝으로 짧은 발화 audio-gap이 음수→양수로 전환됨 (stage1 0.2725, stage2 0.3348)
- 데이터 증량(480→2485)으로 이 효과가 재현 + 강화됨
-> 즉, 파인튜닝이 짧은 발화에서 오디오 의존도를 높인다는 가설은 입증

[ 확인된 한계 ]
- 짧은 발화 개선은 "오디오 의존 상승 + 환각성 과생성 억제"의 혼합 효과 -> 순수 오디오 의존만은 아님
- 긴 발화에서 step2 파인튜닝 후 무음 입력 시 대화체 상투어/반복 루프 생성 부작용 발생
-> 이건 KconfSpeech 대화체 패턴 과학습 때문으로 추정
```
