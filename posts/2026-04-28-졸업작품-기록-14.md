# ML 학습 데이터 수급 계획 확정

> 사전 테스트로 Fine-tuning이 핵심 과제라는 걸 확인하고 나서,
> 어떤 데이터로 학습시킬 건지를 구체적으로 정리했다.
> 데이터 소스를 뒤지고, 직접 청취하고, 자동화 스크립트까지 돌린 과정을 기록한다.

---

## 학습 순서

무작정 데이터를 다 모아서 한 번에 학습시키는 게 아니라 두 단계로 나눴다.

- 공개 데이터셋으로 1차 Fine-tuning
- 검증 (클래스별 정확도 측정)
- 직접 녹음 데이터 추가 후 2차 Fine-tuning

직접 녹음이 준비되기 전에 공개 데이터로 먼저 돌려보고 어디서 성능이 부족한지 확인한 다음, 녹음 데이터로 보완하는 구조였다.

---

## 데이터 소스별 수급 결과

### 초인종

| 소스 | 수량 | 비고 |
| --- | --- | --- |
| FSD50K | 107개 | WAV 44.1kHz, CC-BY |
| AudioSet | 88개 | yt-dlp 실제 성공률 73% |
| 직접 녹음 🔴 필수 | 90클립 예정 | 아파트 인터폰 3종 × 거리 3단계 × 10회 |

서양 차임벨 데이터만으로는 한국 인터폰 정확도가 60~75% 수준으로 예상됐다. 한국 아파트 인터폰 특유의 단음 전자음은 공개 데이터셋에 거의 없어서 직접 녹음이 필수였다. 문 닫힌 상태 녹음 시나리오도 포함할 예정인데, 실제 배포 환경이 문 너머 소리를 감지하는 구조이기 때문이다.

### 노크

| 소스 | 수량 | 비고 |
| --- | --- | --- |
| FSD50K | 270개 | WAV 44.1kHz, CC-BY |
| AudioSet | 110개 | yt-dlp 실제 성공률 92% |
| 직접 녹음 🟠 필요 | 180클립 예정 | 문 재질 3종 × 세기 3단계 × 거리 2단계 × 10회 |

### 화재경보

화재경보는 데이터 선별 과정이 가장 복잡했다.

| 소스 | 수량 | 결과 |
| --- | --- | --- |
| AI Hub S_103 | 171개 | ✅ 사용 — 한국 KC 인증 단독경보형 실측 |
| FSD50K Alarm 435개 | 제외 | 표본 청취 결과 차량 사이렌 위주 |
| AudioSet fire_alarm 100개 | 제외 | RMS 분석 결과 65% 차량 사이렌 확인 |
| 직접 녹음 🔴 필수 | 240클립 예정 | 장소 2 × 거리 4 × 배경소음 3 × 10회 |

FSD50K Alarm 클립 1,280개 중 자동 필터(차량 관련 태그 제거)를 돌려서 후보 435개로 줄인 다음, 30개를 직접 청취했는데 대부분 차량 사이렌이었다. AudioSet fire_alarm도 RMS 분석으로 확인해보니 65%가 차량 사이렌이었다. 둘 다 제외하고 AI Hub 171개 + 직접 녹음 240개로 완전 대체하기로 확정했다.

## 전처리 기준

| 항목 | 기준 |
| --- | --- |
| 샘플레이트 | 16kHz mono 변환 |
| 클립 분할 | 3초 고정 (stride=3) |
| YAMNet 입력 | raw waveform 직접 입력 (16kHz mono · 3초 = 48,000 samples) |
| train/val 분할 | **파일 단위 분할 필수** |

YAMNet 입력 방식에서 초기에 혼동이 있었는데, YAMNet은 멜 스펙트로그램이 아니라 **raw waveform을 직접 입력** 받아야 한다. 내부에서 64-bin mel-spec을 자동으로 생성하는 구조라서 librosa로 멜 스펙트로그램을 뽑아서 넣으면 동작하지 않는다.

train/val/test 분할도 파일 단위로 해야 했다. 클립 단위로 랜덤 분할하면 같은 원본 파일에서 나온 클립이 train과 val에 동시에 들어가서 data leakage가 생기기 때문이었다.

## Augmentation 전략

| 기법 | 파라미터 | 적용 대상 |
| --- | --- | --- |
| time-stretching | ×0.85, ×1.15 | 전체 |
| background noise | SNR 10/20dB | 초인종·노크 |
| background noise | SNR 25/35dB | 화재경보 |
| volume scaling | -6dB | 전체 |
| pitch-shifting | -2/+2 semitone | 한국 환경음만 |
| SpecAugment | freq_mask=10, time_mask=5 | 전체 (학습 시 on-the-fly) |

서양 클립은 원본 포함 8개, 한국 클립은 원본 포함 10개로 생성한다.

Augmentation 후 최종 학습량 추정치는 초인종 ~4,400개, 노크 ~7,500개, 화재경보 ~16,000개인데, 화재경보:노크:초인종 비율이 약 6.7:3.3:1로 클래스 불균형이 상당하다. `class_weight` 적용이 필수고, 한국 환경음 샘플에는 `sample_weight` 1.5~2.0배 가중치를 줄 예정이다.

## 직접 녹음 계획

직접 녹음은 세 가지가 남아 있었다.

- **초인종 🔴**: 아파트 인터폰 3종 접근 확보 (지인 섭외) + 단독경보형 감지기 구매 필요
- **화재경보 🔴**: KC 인증 단독경보형 감지기 구매 (쿠팡, 1~2만원대) + 9V 배터리
- **노크 🟠**: 장비 외 별도 준비 필요 없음

## 정확도 예측

| 시나리오 | 예상 정확도 |
| --- | --- |
| 직접 녹음 완료 + 전처리 정상 | 90~93% (추정) |
| 직접 녹음 없을 경우 | 75~82% (추정) |

최근 관련 논문들을 보면 YAMNet embedding 기반 Fine-tuning으로 94~95% 달성 사례도 있었다. raw waveform 입력 방식을 지키면서 직접 녹음까지 확보하면 90% 목표 달성이 현실적이라는 판단이었다.
