### 졸업작품 시작 - 실내 환경 이상 감지 시스템 (브레인스토밍)

> 전자컴퓨터공학과 21학번 박태근입니다.
> 졸업작품 개발 과정을 처음부터 끝까지 기록해두려고 합니다.
> 잘 정리된 글보다는 **실제로 어떻게 생각하고 결정했는지**가 남는 기록이 되었으면 합니다.

---

## 어떤 주제를 선택했나

**실내 환경 이상 감지 시스템**입니다.

한 줄로 요약하면,

> 방 안에 센서를 달아서 온도·습도·가스 수치를 실시간으로 수집하고, 머신러닝 모델이 정상 패턴을 스스로 학습하여 이상 징후를 자동으로 탐지하는 시스템

이상이 감지되면 TM4C 보드 LCD 화면과 웹 대시보드에 즉시 경보를 띄웁니다.

---

## 왜 이 주제인가

### 임베디드 수업에서 출발

동기는 수강한 임베디드 수업이었습니다. TM4C 보드로 LCD에 무언가를 띄우고, UART로 PC랑 통신하는 걸 배우면서 이게 단순 실습이 아니라 실제로 데이터를 주고받는 시스템의 핵심이라는 걸 느꼈습니다.

여기서 한 발 더 나아가서 실제로 의미 있는 데이터를 수집하고 활용하는 걸 해보고 싶었습니다.

### 왜 '환경 감지'인가 - 데이터가 뒷받침한다

주제를 고를 때 *임베디드로 뭘 측정하면 실생활에서 의미가 있을까*를 먼저 생각했습니다.

단순한 아이디어가 아니라 실제 데이터가 뒷받침합니다.

- **소방청 화재통계연감** 기준, 2023년 한 해에만 전국에서 화재가 **38,857건** 발생했고 사망 284명, 부상 2,204명의 인명피해가 났습니다.
- **한국화재보험협회** 자료 기준, 최근 5년간 가스 사고는 연평균 **81.8건** 발생했고 화재·폭발을 동반하는 경우가 많아 대형 인명피해로 이어지는 경우가 많습니다.

이런 사고 대부분이 초기에 이상 징후만 감지됐어도 막을 수 있었던 경우입니다. 특히 혼자 사는 자취방이나 좁은 작업실처럼 항상 주의를 기울이기 어려운 공간에서 이런 시스템이 실질적인 도움이 될 수 있다고 생각했습니다.

---

## 시스템 전체 흐름

```
[Sensor] → [TM4C 보드] → [Flask 서버] → [ML 판단] → [경보]
```

| 단계 | 역할 |
| --- | --- |
| Sensor | DHT22(온습도), MQ-2(가스) 센서로 실내 환경 측정 |
| TM4C 보드 | 센서 데이터를 읽어 UART 통신으로 서버에 전송 |
| Flask 서버 | 데이터 수신·DB 저장 및 ML 모델에 판단 요청 |
| ML 판단 | Isolation Forest 알고리즘이 정상 패턴 기반으로 이상 여부 판단 |
| 경보 | 이상 감지 시 보드 LCD와 웹 대시보드에 즉시 경보 표시 |

---

## 왜 머신러닝인가

처음엔 단순하게 *온도가 40도 넘으면 경보* 방식으로 만들 수도 있었습니다. 근데 이 방식엔 한계가 있습니다.

- 여름철엔 원래 환경 온도가 높음
- 요리할 땐 가스 수치가 올라가는 게 정상
- 상황마다 임계값을 일일이 정해주는 건 현실적으로 불가능

이걸 **단순 임계값 방식의 한계**라고 부르기로 했습니다.

### Isolation Forest 선택 이유

선택한 알고리즘은 **Isolation Forest**입니다. 비지도 학습 계열의 이상 탐지 알고리즘입니다.

핵심 아이디어는 하나입니다.

> "이상한 데이터는 정상 데이터보다 훨씬 빨리 고립된다"

정상 데이터는 분포상 한곳에 몰려있고, 이상 데이터는 혼자 동떨어져 있습니다. 랜덤하게 선을 그어서 데이터를 고립시킬 때, 이상 데이터는 몇 번 만에 고립되고 정상 데이터는 훨씬 많은 횟수가 필요합니다. 이 횟수 차이로 이상 여부를 판단합니다.

**이 알고리즘을 고른 결정적인 이유**는 정상 데이터만으로 학습이 가능하다는 점입니다. 가스 폭발이나 화재 같은 이상 데이터를 실제로 만들어낼 수 없는 상황에서 이 점이 핵심적인 장점입니다.

1초마다 데이터를 수집하면 하루에만 수만 개의 데이터가 쌓이고, 이를 바탕으로 모델이 이 공간의 정상 범위를 스스로 학습합니다. 이후 들어오는 데이터가 그 범위에서 벗어나면 자동으로 이상 징후로 판단하게 됩니다.

## 기술 스택

| 파트 | 기술 |
| --- | --- |
| 임베디드 | TM4C129 Cortex-M4, C, GPIO, ADC, UART |
| 백엔드 | Python, Flask, SQLite, pyserial |
| ML | scikit-learn, Isolation Forest |
| 프론트 | HTML, JavaScript, Chart.js |

하드웨어 구현 방법도 현실적입니다. 수업에서 사용한 TM4C 보드의 핀에 온습도 센서와 가스 센서를 점퍼선으로 꽂아 연결하는 방식으로, 수업에서 배운 GPIO와 ADC를 그대로 활용합니다.

## 향후 확장 계획

현재는 브레인스토밍 단계이지만, 시스템이 완성되면 아래 기능까지 확장할 생각입니다.

1. **자동 신고 연동** - 보호자 연락처를 미리 등록해두면 이상 감지 시 자동으로 알림 전송
2. **모바일 알림** - 카카오톡 API 연동으로 외출 중에도 실시간 경보 수신
