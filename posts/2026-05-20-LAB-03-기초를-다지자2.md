왜 시간 정렬이 어려울까??

잘은 모르지만 내 생각으로 실제 연구 상황은 이럴 것이다.

- 음성:     16,000 Hz  (1초에 16,000번 측정)
- EEG:         500 Hz  (1초에 500번)
- 아이트래커:   120 Hz  (1초에 120번)
- 심박:         10 Hz  (1초에 10번)
- 영상:          30 Hz  (1초에 30번)
- 텍스트:        1 Hz   (1초에 1번, 발화 단위)

문제는 이 정보들을 모두 "오후 2시 35분 12.345초에 무슨 일이 있었나?" 라는 질문에 답할 수 있게 합쳐야 한다는 것이다.

그래서 이번 실습에서는 **텍스트(1Hz)와 심박(10Hz) 두 개만 가지고 작은 버전으로 연습**하기로 했다.

---

실습을 위해 현실적인 데이터로 DataFrame을 생성해보자.

```python
# 현실적인 데이터: 텍스트가 어중간한 시간에 발화
realistic_text = pd.DataFrame({
    'time': [0.35, 1.27, 2.81, 3.42, 4.69], # 일부러 어중간한 시간
    'speaker': ['A', 'B', 'A', 'C', 'A'],
    'text': ['오늘 회의 시작', '네 좋아요', '안건은 예산', '음 글쎄요', '의견 주세요']
})

print("현실적인 텍스트 데이터")
display(realistic_text)
```

또한 merge를 시켜주기 위해 심박 DataFrame을 생성해보자.

```python
# 심박 데이터: 0.1초마다 측정 (10Hz, 5초간 = 50개)
heart_times = np.arange(0, 5, 0.1)
heart_rates = 75 + np.random.randint(-5, 20, size=len(heart_times))

heart_data = pd.DataFrame({
    'time': heart_times,
    'heart_rate': heart_rates
})

print("심박 데이터 (10Hz)")
print(heart_data.head(10)) # 처음 10개만
print(f"\n총 {len(heart_data)}개의 측정값")
```

### 여기서 이제 나는 두 dp를 병합하는 Merge 작업을 실행할 것이다.

#### [ 1. 일반 merge로 시도 ]

코드를 입력해보자.

```python
naive_result = pd.merge(realistic_text, heart_data, on='time')
print(f"일반 merge 결과: {len(naive_result)}개 행")
display(naive_result)
```

위 코드의 결과는 **일반 merge 결과: 0개 행**이다.

생각해보자, 왜 이런 결과가 나올까?

답은 간단했다. 정확히 time이 일치하는 행끼리만 합쳐져서 모든 발화 시점에 그 순간의 심박을 알고 싶은데 일치하는 시간이 드물다는 문제 발생한 것이다.

그래서 나온 방법이 다음 방법이다.

#### [ 2. merge_asof ]

```python
asof_result = pd.merge_asof(realistic_text, heart_data, on='time', direction='nearest')
print(f"merge_asof 결과: {len(asof_result)}개 행")
display(asof_result)

# direction 옵션 종류
# 'nearest': 가장 가까운 시간 (앞이든 뒤든)
# 'backward': 그 시간 이전의 가장 최근 값 (기본값)
# 'forward': 그 시간 이후의 가장 가까운 값
```

그랬더니 똑같은 dp들에 대해서 결과는 앞 방법과는 달랐다.

### 마치며.

`merge`와 `merge_asof`. 이름은 한 글자 차이지만, 결과는 0개와 5개의 차이였다.

처음엔 "어차피 시간 컬럼 있으니까 merge하면 되겠지"라고 생각했는데, 결과를 보고 한 대 맞은 기분이었다. **실제 연구 데이터는 깔끔하게 떨어지지 않는다.** 발화는 정확히 1초 단위로 일어나지 않고, 심박은 발화 시점을 신경 쓰지 않고 자기 속도대로 측정된다.

그래서 필요한 게 **"적당히 가까우면 매칭하기"** 라는 유연함이었고, `merge_asof`가 그걸 해줬다.

이번 실습은 작은 두 개의 DataFrame으로 했지만, 실제 연구에선 6개의 신호(EEG, 음성, 영상, 심박, 시선, 텍스트)를 모두 시간축에 맞춰야 한다.
