## 프로빙

모델을 건드리지 않고 모델이 내부적으로 만든 표현(임베딩) 위에 일부러 약한 분류기를 하나 얹어서 "이 표현 안에 특정 정보(감정)가 이미 들어 있나?"를 묻는 실험이다.

약한(선형) 분류기를 사용하는 이유: 딥 MLP 같은 강한 분류기를 쓰면 분류기가 임베딩에서 감정 매핑을 스스로 학습해버릴 수 있어, 점수가 높아도 원래 임베딩에 감정이 있었던 건지 분류기가 만들어 낸 것인지 구분이 안 된다. 선형 분류기는 직선 하나로만 가를 수 있어 임베딩 안에서 감정이 이미 선형적으로 분리 가능한 형태로 정리돼 있어야만 점수가 나온다. 그래서 **선형 프로브의 성공은 모델 표현이 감정을 이미 접근 가능한 방식으로 조직해 놨다는 증거**다.

## 왜 baseline 대조가 필수인가

오디오 프로브 점수 하나만으로는 의미가 없다.

- 오디오 채널: audio 임베딩 → 선형 프로브 → 감정 정확도
- 텍스트 채널: 같은 발화의 전사 텍스트 → 텍스트 임베딩 → 같은 선형 프로브 → 감정 정확도

두 점수를 비교해 오디오 ≫ 텍스트면 → "텍스트가 버린 감정 신호를 오디오가 들고 있다" = 가설("표면 발화 불충분 → 멀티모달 필요")의 직접 증거가 된다.

### 텍스트 통제 설계

일반 감정 데이터셋을 그냥 쓰면 함정이 있다 — 텍스트가 감정을 단어로 잘 맞혀버릴 수 있다("짜증나" 같은 감정 어휘 존재). 그러면 텍스트 채널도 점수가 높아져 대조가 흐려진다. 그래서 텍스트가 같거나 거의 같은데 정서만 다른 발화쌍이 필요하다. 텍스트를 상수로 고정하면 운율 신호만 분리되어, "오디오에 감정이 있다"가 아닌 **"텍스트가 못 잡는 감정이 오디오에 있다"**를 증명하게 된다.

## 목표

임베딩 프로빙 실험은 "텍스트만 줄 때 vs 똑같은 텍스트에 음성까지 줄 때" 모델의 출력 차이를 보는 게 아니라, 그 두 조건에서 **모델 내부 표현(임베딩)에 담긴 감정 정보량의 차이**를 외부의 약한 선형 프로브로 측정하는 것이다. 모델은 표현만 만들고 감정 분류는 프로브가 그 표현을 읽어 수행한다. 출력이 아니라 표현을 보는 이유는 음성에 감정 신호가 있어도 모델이 출력에 안 써서 "없다"는 결과가 나올 수 있기 때문이다. 결국 "프로브는 음성 표현에서 감정을 찾는데(신호 존재) 모델 출력은 안 변한다(모델이 안 씀)"는 간극 자체가 "신호는 있으나 모델 낭비" → 멀티모달 필요성이다.

## 사용할 데이터셋

- 자연발화: 대본 없이 진행된 자유대화 → 진짜 운율이 살아있어 연기체가 아님
- 짧은 발화 + 텍스트 통제 쌍
- 발화단위 감정 라벨(상태 7종 + 유형 3종) + 전사 + wav 보유

### 1. 라벨 데이터(정답지) 분석

- 발화 210만 개, ≤3초가 73%: 짧은 발화가 데이터의 대부분
- 감정 긍정 59% 쏠림: 그냥 쓰면 분류기가 "다 긍정"이라 찍어도 59%로 맞음 → 균형을 맞춰야 진짜 실력이 보임
- 9,469종 / "네" 41,024회 ×3감정: 같은 글자가 여러 감정으로 나오는 경우가 압도적 = 텍스트 통제 실험 가능
- 토큰 × 감정 표(음/어/네…): 토큰마다 긍·중·부가 다 있고 소수인 부정도 수천 개 → 균형 잡아 학습 가능

"네" 하나로 예를 들면: "네"라고 말한 오디오 조각들을 다 모으고(글자는 전부 동일), 각 "네"의 소리를 Gemma의 audio tower에 통과시켜 임베딩을 뽑은 뒤, 그 메모만 보고 감정을 맞히는 선형 분류기를 학습시킨다. 핵심은 글자가 전부 똑같은 "네"라서 글자로 감정을 맞히는 건 불가능(운에 맡기는 수준)인데, 소리(임베딩)로 맞힌 게 운보다 잘 나오면 → **감정이 글자엔 없고 소리에 들어있다는 증거**다.

이 실험은 "텍스트만으론 부족 → 운율(오디오) 필요 → representation-level fusion 필요"를 추측이 아니라 데이터로 증명하는 단계다.

이전 회의 음성 데이터로 한 ASR 실험과 차이점:
- ASR 실험: 모델이 뱉은 출력(전사 텍스트)을 봄 → 받아쓴 단어가 맞나(CER/WER/환각). **말의 내용**.
- 프로빙: 모델 내부 표현(임베딩)을 봄 → 모델은 아무것도 뱉지 않음(그 표현 안에 감정이 들었나). **말의 정서**.

단어를 잘 받아쓴다와 감정을 담는다는 다른 문제다. ASR 학습은 단어 맞히는 것만 보상하니 모델이 단어는 잘 받아쓰면서 감정은 통째로 무시했을 수 있다. 그래서 감정이 표현에 남아있는지 따로 확인한다.

### 2. 원천 데이터(실제 녹음 파일) 분석

실제 오디오 파일이 있는 발화만 남겼더니 211,678개가 남았고, 그 중 네/어/음 세 토큰만 추렸다(글자가 100% 같은 발화들). 토큰마다 긍정·부정·중립을 소수 클래스에 맞춰 균형 있게 개수를 통일했다.

네·어·음으로 고른 이유: 전사 텍스트는 모두 동일한데 감정이 각각 다르다 → 텍스트로 감정을 맞히는 분류기에게 주면 입력이 전부 똑같아 구분 불가 → 이 셋의 감정을 오디오로 구별할 수 있으면 감정 정보는 글자엔 없고 소리에만 있다는 게 증명된다. 감정이 오직 말투에만 실리는 순수 운율 단어이며, 양이 충분하고 세 감정이 모두 존재한다.

프로브 실험의 입력 데이터 만들기: 매니페스트 3,369개 = 네/어/음 토큰, 각각 긍/부/중 감정으로 균형 맞춘 것. 같은 '음'이라도 긍정으로 낸 '음'과 부정으로 낸 '음'이 섞여 있고 글자가 다 똑같아 텍스트로는 구별 불가. 각 발화의 오디오 조각을 오디오 타워에 통과시켜 모델 내부 표현(1536차원 벡터)으로 변환해 저장했다(발화 하나당 1536차원 벡터 하나).

## 프로브 실험

저장된 발화당 1536차원 벡터 위에 약한 선형 분류기로 감정 3분류 실험을 설계했다.

핵심 통제: 글자가 같으니 텍스트 분류기는 설계상 chance(0.333). 그래서 프로브가 감정을 맞추면 그 정보는 소리에서만 온 것이다.

**결과**: 같은 글자라도 긍/부/중이 오디오타워 표현에서 선형으로 갈린다. → 감정은 글자가 아니라 소리에 있다. → 즉, 모델은 감정을 표현에 갖고 있고 글자로 옮길 때만 버린다.
