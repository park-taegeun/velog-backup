근데 그린루키 신청 메일 보내기 전에 한 가지 검증할 게 있었다 — 서경대가 NCP 그린루키 제휴 학교인지 아닌지부터 확인하는 거였고, 결과적으로 이 사전 검증 12분이 그 다음 며칠을 절약했다.

## "100,000원 / 100일"? 아니, "100,000원 / 3개월"

처음에 정보 정리할 때 AI한테 NCP 기본 크레딧 정책을 물어봤더니 "100,000원 / 100일"로 박혀서 나왔다. 일반적으로 외국 클라우드 무료 크레딧 정책이 "X일" 단위로 끊기는 패턴이 많아서 그렇게 박힌 것 같았는데, 실제 NCP 가입 화면 직접 들어가서 보니까 "100,000원 / 3개월" 이었다.

차이가 작아 보이지만 100일이면 ~2026-08-24, 3개월이면 ~2026-08-16이라 만료 catch 시점이 8일 빨라졌다. 그리고 본 프로젝트는 11~12주차(7/27~8/9)에 Naver Clova Speech를 본격적으로 쓰기 시작하니까, 8월 중순 만료 시점이 사용량 trace 시점과 정확히 겹쳤다. 자동 결제가 활성화돼 있어서 만료 직후 과금이 트리거되는 구조라 만료일 정확도가 무료 크레딧 소진 catch에 직접 영향을 줬다.

이게 그래서 학습 패턴 하나 잡힌 게, AI가 일반 패턴으로 박은 수치보다 학부생 본인이 화면 catch한 수치가 우선 이라는 거였다. 5/12에 "보고 요약 vs 실제 파일" 갭, 5/13에 "인계 패키지 vs 실제 SSoT" 갭에 이어서, 5/16은 "AI 일반 패턴 박기 vs 화면 직접 catch" 갭. 같은 류의 catch가 layer만 바뀌어서 계속 잡혔다.

## Clova Speech 단가 catch

기본 크레딧 100,000원이 본 프로젝트 사용량에 충분한지도 같이 catch했다. Naver Clova Speech 단가는 초당 0.5원(분당 30원) 이었고, 띵동의 STT 호출 패턴(2차 알림 시 5초 추가 녹음)으로 추정해보니 월 1,000~3,000원 수준이었다. 100,000원 크레딧 안에 한참 안전 수렴이었다.

8/16 만료 후 자동 과금이 트리거되긴 하는데, 11~12주차 진입 시점에 사용량을 확인해서 크레딧이 거의 안 빠지고 있는 게 catch되면 추가 조치 없이 그대로 가도 됐다.

## 그린루키 — 메일 보내기 전에 사전 검증부터

그린루키는 NCP의 학생 무료 크레딧 프로그램으로, 기본 10만원 + 추가 20만원해서 총 30만원 크레딧 을 받을 수 있는 구조였다. 졸작 학부생 입장에서 20만원 추가는 안 받을 이유가 없었고, 신청 절차도 학과 메일 발송으로 비교적 단순했다.

근데 신청 메일 보내기 전에 한 가지 검증할 게 있었다 — 서경대가 그린루키 제휴 학교인지. 제휴 학교가 아니면 신청 메일은 거절 답변으로 돌아오고, 답변 받는 데 5/18~5/19 평일 진입을 기다려야 했다. 메일 작성 + 발송 자체는 5분이면 끝나지만, 거절 답변 받는 데 며칠 묶이는 게 더 큰 손실이라는 판단이었다.

본 채팅방에서 한 번 web_search로 catch 시도해봤는데 한계가 있었고, 그래서 Claude Code MCP에 위임했다. 12분 만에 결과 도착, 예상 20~30분 대비 단축됐다.

### 3중 출처 일관 catch — 미제휴 확정

| 출처 | catch 결과 |
| --- | --- |
| NCP 공식 명단 32개 기관 | 서경대 부재 (playwright 동적 로딩 catch) |
| 서경대 산학협력단 + 메인 사이트 | NCP / 그린루키 안내 0건 |
| 비공식 (블로그 / Velog / Tistory) | 서경대 학생 그린루키 신청 사례 0건 |

대조군으로 아주대 / 서울대를 같이 찍어보니까 학교 공지나 학생 블로그 사례가 다수 있었다. 서경대만 모든 출처에서 일관 부재였고, 이건 사실상 미제휴 확정 으로 봐도 됐다.

### 결정: 옵션 B 채택 — 메일 발송 X

- 옵션 A: 그린루키 신청 메일 발송 → 5/18~5/19 거절 답변 회피
- 옵션 B: 메일 발송 X, 기본 크레딧 100,000원으로 운영 (채택)
- 옵션 D: 서경대 산학협력단에 NCP 그린루키 제휴 추진 메일 (후배 가치 창출) → 5/18 이후 평일 진입 시 재결정

옵션 B로 채택했고, 옵션 D는 평일 진입 시 따로 결정하기로 미뤘다. Clova Speech 추정 사용량(월 1,000~3,000원)이 기본 크레딧 100,000원 안에 안전 수렴이라 그린루키 20만원 추가가 안 들어와도 일정상 무리 없었다.

## 12분의 가치

이 사전 검증의 핵심은 메일 5분 + 답변 며칠 묶이는 시나리오를 12분 투자로 회피한 것 이었다. 단기 손실 12분 vs 단기 이득 며칠 catch 회피 → ROI가 명확했다.

이 패턴도 같은 류의 catch였다 — 외부 서비스(NCP / 학과 메일 같은) 진입 전에 사전 검증을 강제하지 않으면 헛수고가 발생한다는 거. 5/12, 5/13에 잡혔던 "실제 SSoT 직접 catch" 패턴이 외부 서비스 시나리오로 확장된 형태였다.
