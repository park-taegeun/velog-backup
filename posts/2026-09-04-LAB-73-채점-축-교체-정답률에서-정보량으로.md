## 방향성 1

### 실험 배경

지금까지 어조의 기여는 감정 8종 정답률로만 판정해왔음
그런데 모델은 8종 전부에 확률을 부여함
-> 얼마나 확신했는지가 버려짐

### 3가지 채점 방식

- 정답률: 1등으로 고른 감정이 정답인지만 확인함 (기존 방식)
- 정보량: 정답 라벨에 부여된 확률에 로그를 취해 비트 단위로 측정함 -> 얼마나 확신했는지를 반영함
- 발화 단위 승률: 4,406 발화를 하나씩 보며 두 조건 중 어느 쪽이 정답에 더 높은 확률을 주었는지 세고 그 비율을 냄 -> 크기를 보지 않고 부호만 보므로 극단값의 영향을 받지 않음

### 결과

**[ 그래프 읽는 법 ]**

- 위 세 결과는 같은 세 성분(감정 수준, 발화 개별, 순효과)을 서로 다른 채점 방식으로 잰 결과
- 가로 검은 선이 기준선
- 막대가 기준선 위 = 그 성분이 판단에 정보를 공급했다는 뜻
- 막대가 기준선 아래 = 그 성분이 판단을 방해
- 막대 위아래로 뻗은 세로선은 95% 신뢰구간 -> 4,406 발화를 복원추출로 다시 뽑아서 평균을 내는 과정을 2,000번 반복했을 때 값이 흔들리는 범위
- 세로선이 기준선에 닿지 않으면 표본을 다시 뽑아도 부호가 유지
- 기준선을 가로지르면 부호가 뒤집힐 수도 있다는 뜻
- 즉, 막대 높이보다 세로선이 기준선을 넘는지가 판정 근거

**[ 정답률로 채점 ]**

기존 방식의 결과: 감정 수준 +3.06%p / 발화 개별 -0.95%p / 순효과 +2.11%p

발화 개별 성분만 기준선 아래 -> 이 값이 "진짜 소리가 판단을 방해한다"로 읽혀왔음 -> 세 설계 내내 음수였고 원인은 규명되지 않음

신뢰구간이 없는 이유 -> 기존 결과가 McNemar 검정 p값으로만 있고 신뢰구간을 산출하지 않았음

**[ 정보량으로 채점 ]**

```
감정 수준 +0.074비트 [+0.008, +0.142]
발화 개별 +0.012비트 [-0.065, +0.089]
순효과   +0.086비트 [+0.021, +0.156]
```

발화 개별 성분의 부호가 양수로 바뀜 -> 그러나 신뢰구간이 0을 포함함 -> "기여한다"고 말할 수 없고 "판별되지 않는다"가 정확한 진술

감정 수준과 순효과는 신뢰구간이 0을 넘지 않음 -> 정답률에서의 결론이 그대로 유지됨

순효과 +0.086비트 = 어조 벡터가 텍스트 위에 얹은 정보량 -> 선행 연구에서 프로소디의 고유 정보량이 비꼼 0.20비트, 정서 0.46비트로 보고됨 -> 같은 자릿수에 놓임

**[ 발화 단위 승률로 채점 ]**

```
감정 수준 53.77% [52.29, 55.17]
발화 개별 49.93% [48.41, 51.45]
순효과   52.68% [51.13, 54.20]
```

발화 개별 성분이 49.93% -> 진짜 소리가 나은 발화와 남의 소리가 나은 발화가 거의 정확히 반반 -> 정보량에서 미세하게 양수였던 것은 소수 발화가 만든 값

이 지표는 크기를 보지 않고 부호만 보므로 극단값의 영향을 받지 않음 -> 정보량 평균이 흔들릴 때 판정의 기준이 됨

**[ 세 결과 종합 ]**

감정 수준 성분과 순효과는 세 방식 모두에서 기준선 위, 신뢰구간도 기준선을 넘지 않음 -> 어조 정보가 판단에 기여한다는 결론은 채점 방식에 의존하지 않음

발화 개별 성분은 세 방식에서 위치가 다르나 두 방식에서 신뢰구간이 기준선을 포함 -> "진짜 소리를 주면 판단을 방해한다"는 진술은 성립하지 않음 -> 그 음수는 정답률이라는 채점 방식에서만 나타남 -> 다만 "기여한다"고도 말할 수 없음. 어느 방식에서도 0과 구분되지 않음

### 결론

채점 방식을 바꿔보니 결과가 두 종류로 갈렸다

흔들리지 않는 것
- 감정 수준 성분, 순효과
- 세 방식 모두에서 기준선 위, 신뢰구간도 넘지 않음
- 어조 정보가 기여한다는 결론은 어떻게 재든 유지됨

흔들리는 것
- 발화 개별 성분
- 정답률에서만 음수이고 다른 두 방식에서는 재현되지 않음

그래서 "진짜 소리가 판단을 방해한다"는 진술은 더 이상 쓸 수 없다. 그 음수는 정답률이 확신도를 버리기 때문에 생긴 값이었다.

세 설계를 거치는 동안 이 음수의 원인을 계속 찾아왔는데, 찾을 대상 자체가 아니었을 가능성이 생겼다.

다만 "기여한다"고도 말할 수 없다. 세 방식 모두에서 0과 구분되지 않는다는 것까지가 말할 수 있는 내용이다.
