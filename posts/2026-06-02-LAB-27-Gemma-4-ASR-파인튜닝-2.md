## DataCollator

#### 필요한 이유

- 학습은 여러 건을 한 번에(batch) 먹이는 과정
- 문제는 샘플마다 길이가 제각각

```text
샘플 A: "감사합니다"        → 67 토큰,  오디오 163 프레임
샘플 B: "어 그렇지만..."   → 200+ 토큰, 오디오 900+ 프레임
```

- 컴퓨터: 길이가 다른 것을 한 묶음으로 못 쌓음
- 짧은 걸 긴 것에 맞춰 빈칸으로 채우는 padding 작업 필요
- 또한 패딩한 곳은 따로 표시를 해줘야 모델이 학습 때 사용하지 않음

즉, DataCollator = "여러 건 묶고 + 길이 맞추고 + 빈칸 표시" 자동 처리기

```text
pad_token_id: 0 -> '<pad>'
eos_token_id: 1
padding_side: left

input_features dtype: torch.float32
input_features_mask dtype: torch.bool
mm_token_type_ids dtype: torch.int64

mm_token_type_ids 고유값: [0, 3]
```

위 결과를 보면

- pad_token_id = 0, padding_side = left ← 왼쪽으로 패딩 채움
- input_features: float32, input_features_mask: bool (False로 패딩)
- mm_token_type_ids: int64, 값은 0(텍스트)/3(오디오)

#### 길이 다른 2개 샘플로 배치 패딩 테스트

![](https://velog.velcdn.com/images/xorms/post/e77e2b22-a138-47da-a38a-a2ca610ac46b/image.png)

- input_ids: (2, 619): 샘플 2개(배치 크기), 619(토큰 길이)
  → 짧은 샘플(67토큰), 긴 샘플(619 토큰) 두 개 넣었는데 619 토큰으로 통일 → 패딩 성공
- input_features: (2, 2035, 128): 샘플 2개(배치 크기), 2035(오디오 프레임 수)
  → 마찬가지로 길이가 다른 두 개를 넣었는데 통일 성공

## 1. DataCollator 생성

```python
# DataCollator 커스텀
class ASRDataCollator:
    def __init__(self, processor, prompt="이 음성을 한국어로 전사하세요."):
        self.processor = processor
        self.prompt = prompt

    def __call__(self, examples):
        # examples: list of dict (session, wav, ref, ref_len)
        convs = []
        for ex in examples:
            audio, _ = librosa.load(ex["wav"], sr=16000)
            convs.append([
                {"role": "user", "content": [
                    {"type": "audio", "audio": audio},
                    {"type": "text", "text": self.prompt},
                ]},
                {"role": "assistant", "content": [{"type": "text", "text": ex["ref"]}]},
            ])

        # 배치 토큰화 + 패딩 (프로세서가 처리)
        batch = self.processor.apply_chat_template(
            convs, tokenize=True, return_dict=True,
            return_tensors="pt", padding=True,
        )

        # 라벨 생성: 패딩된 input_ids에 직접 build_labels 적용
        labels = torch.stack([build_labels(batch["input_ids"][i])
                              for i in range(len(examples))])
        batch["labels"] = labels
        return batch

collator = ASRDataCollator(processor)

# 검증: 3개 샘플로 배치 생성
test_batch = collator([train_df.iloc[0].to_dict(),
                       train_df.iloc[1].to_dict(),
                       train_df.loc[train_df["ref_len"].idxmax()].to_dict()])

print("[배치 키/shape]")
for k, v in test_batch.items():
    print(f"  {k}: {tuple(v.shape)}")

# 라벨 검증: 각 샘플의 정답이 제대로 살아있는지
print("\n[샘플별 라벨 디코딩]")
for i in range(3):
    lab = test_batch["labels"][i]
    valid = lab[lab != -100]
    print(f"  샘플{i}: {repr(processor.decode(valid))[:200]}")
```

즉, ***"여러 건 묶기 + 길이 맞추기 + 정답만 표시"***가 한 번에 자동으로 됨
