이전에 Transforemr에 대해서 간략히 알아보았고 다음으로는 BERT와 GPT에 대해서 알아볼 예정이다.
이 2가지 개념은 다른 개념이 아니고 Transformer에서 파생된 개념이라고 볼 수 있다.

2017년에 나온 초기의 Transformer는 각 단어 벡터의 의미를 찾아내는 Encoder와 다음 단어를 예측하는 Decoder이 합쳐진 개념이었다.

하지만 다음 해인 2018년에 이 두 가지 개념을 따로 사용하면 더 효율적으로 사용할 수 있겠다는 생각이 지배적이었고그 과정 속에 대표적으로

```
├─ Google: Encoder만 쓸래 → BERT (2018.10)
└─ OpenAI: Decoder만 쓸래 → GPT (2018.06)
```

이것이 BERT와 GPT 분기의 시작점이다.

---

**[ BERT ]**
- Bidirectional(양방향) Encoder Representations from Transformers

BERT는 문장에서 단어 일부를 가리고 맞추는 게임 방식으로 학습되었다(MLM).
빈칸을 맞추려면 앞/뒤 단어를 모두 봐야했고 이는 양방향성을 의미한다.
이러한 학습 방식을 통해 문장의 의미를 잘 이해하는 모델로 발전된 것이다.

#### [ GPT ]
- Generative(생성) Pre-trained(사전 학습된) Transformer

GERT는 이전까지 본 단어들로 다음 단어를 예측하는 게임 방식으로 학습되었다(CLM).
이는 앞만 보고 다음 단어를 예측하는 단방향성을 가진다.
이러한 학습 방식을 통해서 글을 잘 쓰는 모델로 발전된 것이다.

하지만 이런 GPT 모델도 거대해지면 비싸지지만 분류, 요약, 번역 등 성능이 좋아진다.
ex.. GPT-4, LLaMA-3

다음으로는 **Hugging Face**에 대해서 알아보자.
많이들 Hugging Face를 *"AI 분야의 GitHub같은 인프라"* 라고 의미한다.

Hugging Face 전에는 특정 모델을 사용하고 싶다면

```
1. 논문 다운로드 (PDF)
2. 저자 GitHub 찾아내기
3. 학습 코드 다운로드
4. 코드가 PyTorch? TensorFlow? Theano? 확인
5. 본인 환경에 라이브러리 버전 맞추기 (지옥)
6. 모델 가중치는 어디 있냐고 issue 올리기
7. 답 안 오면 본인이 직접 학습 (GPU 며칠)
8. 드디어 추론 1번 성공
```

위 과정과 같이 굉장히 번거로웠다.

이후에 Hugging Face가 등장하면서 pytorch-pretrained-bert 라는 라이브러리를 만들어서 공유하였고 이로 인해 "누구나 BERT를 3줄로 쓸 수 있게 되었다."

```python
from transformers import pipeline
classifier = pipeline("sentiment-analysis")
result = classifier("I love this movie!")
```

그 후, BERT뿐 아니라 모든 Transformer 모델을 같은 인터페이스로 통합한 transformers 라이브러리로 발전된 것이다.

지금의 Hugging Face는 AI 생태계의 4개 기둥으로 비유할 수 있다.

```
[ Hub ]
- huggingface.co 사이트: 모델 / 데이터셋의 중앙 저장소
- 누구나 모델 업로드 가능, 누구나 다운로드 가능

[ transformers ]
- 모델 사용 표준 인터페이스
- 모든 모델을 같은 방식으로 사용할 수 있음
```

```python
# BERT 쓰기
from transformers import AutoModel, AutoTokenizer
model = AutoModel.from_pretrained("bert-base-uncased")

# LLaMA-3 쓰기 - 똑같음!
model = AutoModel.from_pretrained("meta-llama/Llama-3-8B")

# 한국어 KcBERT 쓰기 - 똑같음!
model = AutoModel.from_pretrained("beomi/KcBERT-base")
# 모델 이름만 바꾸면 끝!!
```

```
[ datasets ]
- 데이터셋 표준 인터페이스
```

```python
from datasets import load_dataset
dataset = load_dataset("klue", "ynat")  # 한국어 뉴스 분류 데이터셋
# 인터페이스와 같은 방식으로 다운로드
```

```
[ Spaces ]
- 모델 데모 호스팅
- 모델 만들고 웹 데모 올리는 무료 호스팅
```

이전에 BERT를 3줄로 사용할 수 있다고 보여준 예시 코드에서
`pipeline("sentiment-analysis")` -> 파이프라인 추상화가 존재한다.

위 코드를 실행시키면
예를 들어 내부에서
1. Hub에서 기본 감정분석 모델 다운로드 (DistilBERT)
2. 모델 가중치 + 설정 로드
3. 토크나이저 다운로드 (텍스트 → 숫자 변환기)
4. 모델을 평가 모드 (eval mode)로 설정
5. 후처리 함수 준비 (출력 숫자 → "POSITIVE" 같은 라벨)

위와 같은 5단계가 자동으로 실행되는 것이다.

**추상화 수준)**

🟢 Level 1: `pipeline()`
"그냥 모델 돌려보고 싶어"
- 3줄로 끝
- 내부 동작 몰라도 됨
- 빠른 프로토타이핑

🟡 Level 2: `AutoModel` + `AutoTokenizer`
"토크나이징, 출력 후처리 직접 컨트롤"
- 10~30줄
- 입출력 흐름 이해 필요
- 파인튜닝 시 필수

🔴 Level 3: 모델 클래스 직접 (`BertModel`, `LlamaForCausalLM` 등)
"모델 내부 레이어 만지고 싶음"
- 50~200줄
- 아키텍처 깊이 이해 필요
- LoRA, 커스텀 헤드 추가 시 사용
