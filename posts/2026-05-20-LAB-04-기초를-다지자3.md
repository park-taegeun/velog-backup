이전 시간 정렬 실습에 이어서 다음으로 한 실습은 "groupby_aggregation"이다.

pandas에서 groupby() 함수를 더 효율적으로 사용하는 방향으로 실습을 진행하였다.

코드를 통해서 실습 내용을 보여주는 것이 좋을 거 같다.

---

```python
import pandas as pd
import numpy as np

# 더 풍부한 회의 데이터 (10명, 30개 발화)
np.random.seed(42) # 결과 재현 가능하게

speakers = np.random.choice(['A', 'B', 'C', 'D'], size=30) # ['A', 'B', 'C', 'D'] 리스트 내에서 30개 랜덤 초이스
texts = ['좋아요', '글쎄요', '확실해요?', '동의합니다', '음...',
         '반대입니다', '괜찮네요', '잘 모르겠어요', '맞아요', '아니요'] * 3 # 10개의 texts 리스트가 3번 반복됨
heart_rates = np.random.randint(65, 105, size=30) # 65 이상 105 미만 사이의 정수를 30개 뽑음
sentiment_scores = np.random.uniform(0.1, 0.95, size=30).round(2) # 0.1 ~ 0.95 사이의 실수를 30개 뽑음(소수점 2자리까지 반올림)
volumes = np.random.randint(40, 85, size=30) # 40이상 85미만 사이의 정수 30개 뽑음

meeting = pd.DataFrame({
    'time': np.arange(0, 30, 1.0), # 0부터 30까지 1.0 간격으로 생성
    'speaker': speakers,
    'text': texts,
    'heart_rate': heart_rates,
    'sentiment_score': sentiment_scores,
    'volume': volumes
})

display(meeting.head(10))
print(f"\n총 {len(meeting)}개 발화")
```

![](https://velog.velcdn.com/images/xorms/post/5186fb8a-d30e-4596-adac-cabc42196af2/image.png)

위 dp에서 화자 별 평균 심장 박동수를 구하려고 하면 어떻게 해야 할까?

이럴 때 필요한 것이 groupby()이다.

**meeting.groupby('speaker')['heart_rate'].mean()**

위 코드 한 줄의 의미는 "meeting dp를 speaker 별로 묶어서 heart_rate를 평균 내줘"

![](https://velog.velcdn.com/images/xorms/post/d22ef0ed-424d-4c6b-9009-53c8694470b6/image.png)

이렇게 간단하게 원하는 결과를 생성할 수 있다.

그렇다면 여기서 한 발짝 더 나아가서, 심장 박동수 컬럼의 여러 통계를 한 번에 뽑고 싶다면 어떻게 해야될까?

바로 agg() 함수를 같이 사용하면 된다.

**meeting.groupby('speaker')['heart_rate'].agg(['mean', 'max', 'min', 'std', 'count'])**

![](https://velog.velcdn.com/images/xorms/post/b0ed43e4-ccac-4298-bc8d-4a0980556cab/image.png)

더!! 나아가서 심장 박동수 뿐 아니라 여러 컬럼들을 다른 집계 방식으로 뽑고 싶다면?

```python
result = meeting.groupby('speaker').agg({
    'heart_rate': ['mean', 'max'], # 심박은 평균과 최대
    'sentiment_score': 'mean', # 감정은 평균만
    'volume': ['mean', 'std'], # 음성은 평균과 표준편차
    'text': 'count' # 발화 횟수
}).round(2)

display(result)
```

### 마치며.

이번 실습으로 `groupby()`의 사용 범위가 한 단계씩 넓어졌다.

| 단계 | 코드 | 결과 |
| --- | --- | --- |
| 기본 | `.groupby('A')['B'].mean()` | A별 B의 평균 |
| 여러 통계 | `.groupby('A')['B'].agg([...])` | A별 B의 평균/최대/최소... |
| 다중 컬럼 | `.groupby('A').agg({컬럼: 함수})` | 컬럼마다 다른 통계 |

처음엔 평균 한 줄이었지만, `agg()`까지 붙이면 **화자별 종합 프로필**이 한 번에 나온다.

groupby()없이는 몇 줄에 걸쳐 작성한 화자별 분석이 결국 한 줄로 끝난다는 게 인상적이었다.

앞으로 연구 데이터에서 "참여자별로", "감정 상태별로", "시간대별로" 통계를 뽑을 일이 많을 텐데, `groupby + agg` 조합이 그 작업의 표준 도구가 될 것 같다는 생각이다.
