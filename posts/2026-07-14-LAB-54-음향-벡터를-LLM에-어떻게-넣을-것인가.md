## 음향 벡터를 LLM에 어떻게 넣을 것인가

음향 특징을 LLM 프롬포트에 넣은 논문을 찾아보았음  

해당 논문들이 한 것:

- 음성에서 숫자를 뽑음
- 그 숫자를 자연어로 바꿈
- 바꾼 말을 프롬포트에 넣음

![](https://velog.velcdn.com/images/xorms/post/7d720141-bcc8-4141-8a21-d502c081a6e8/image.png)

### 1. 왜 LLM에 숫자 그대로 넣지 않는가

#### 1) LLM은 숫자 척도를 잘 못 씀

```
f0_mean: -1.8
f0_mean: -1.9
- 이 둘의 차이를 LLM이 의미 있게 구분하지 못 함

반면:
목소리 높이: 낮음
목소리 높이: 매우 낮음
- 이건 확실히 구분함
```

#### 2) 숫자를하면 LLM이 산수를 하려 한다

```
"-1.8이면 평균에서 1.8 표준편차 아래이고, 정규분포 가정 시 하위 3.6%에 해당하며..."
- 어조를 물었는데 통계 해설을 함
```

### 2. binning

- 숫자를 칸에 넣어서 이름을 붙이는 것

```
[ 5칸으로 설정한 이유 ]
1. 극단값을 살려야하기 때문
2. 선행 연구
- Acoustic Cue Alignment (2026)
- VowelPrompt (2026)

[ 경계를 왜 ±1, ±2에 뒀나 ]
z < ?      매우 낮음
? ~ ?      낮음
? ~ ?      평소 수준
? ~ ?      높음
z > ?      매우 높음

위의 ?를 채워야 함
우리가 다루는 숫자는 z-score
: 평균에서 표준편차 몇 배만큼 떨어져 있나?
- z = 0: 평균과 같음
- z = 1: 표준편차 1배만큼 위
- z = 2: 표준편차 2배만큼 위

정규분포에서는 z값마다 "얼마나 흔한가"가 정해져 있음
-1 ~ +1 사이에    약 68%가 들어감
|z| > 1 인 경우   약 32%
|z| > 2 인 경우   약 5%

-> 정규 분포에서 이미 의미있는 경계가 ±1, ±2인데 이것과 5칸이 맞물림
```

### 3. MFCC 문제

층2는 63차원 -> F0(피치 관련) 11개 + MFCC 52개

F0 11개는 문제 없음

```
f0_mean       →  목소리 높이
f0_range      →  높이 변화 폭
f0_slope_tail →  말끝 억양

전부 말로 옮길 수 있음 = 사람이 귀로 듣는 것과 직접 연결 가능
```

MFCC 52개가 문제

- MFCC는 기계가 먹으라고 만든 숫자
- 스펙트럼을 수학적으로 분해한 계수라 각 계수가 어떤 성질인지 한 문장으로 정의할 수 없음

#### MFCC 52개를 어쩔 것인가

이 52개를 그냥 다 넣으면 LLM 입장에서 읽을 수 있는 11줄(F0)이 못 읽는 52줄에 파묻히게 된다.  

즉, LLM 입장에서 신호 대 잡음이 11:52인 셈이다.  

또한 LLM이 MFCC를 그럴듯하게 지어낼 수 있음

하지만 그렇다고 MFCC를 넣지 않기에는 음색 정보를 통째로 버리는 것

그래서 어떻게 넣을 방법이 없나 찾아봤지만 MFCC를 프롬포트에 넣은 사례는 없었음

Tracey 2023 (Scientific Reports)에서  

![](https://velog.velcdn.com/images/xorms/post/c4d0bd28-cd8a-48a4-a24d-8cee450ca464/image.png)

c0, c1은 뜻을 아니까 그대로 사용

```
c0 → "목소리 크기: 작음"
c1 → "목소리 밝기: 어두움"
```

나머지 50개는 뜻을 모름  

그래서 뜻은 못 말하고, 얼마나 벗어났나만 말함

```
c2~c12 정적 24개  →  "음색이 평소와 다른 정도: 큼"
동적 26개         →  "음색이 변한 속도: 빠름"
```

어떻게 다른지는 안 말함 -> 다르다는 것만 말함

계산은 RMS로 함

- 여러 z값을 크기 하나로 뭉치는 방법
- 그냥 평균을 내면 +와 -가 상쇄됨   (예: +2.1, -1.8, +2.3, -2.0 → 평균 0.15 → "안 벗어났다"는 잘못된 결론)
- 제곱하면 부호가 사라짐 → RMS 2.06 → "많이 벗어났다"가 제대로 나옴
- 또한 z-score의 RMS는 이론값이 1 → "RMS 1 = 평소 수준"이 자동으로 정해짐

단, RMS는 항상 양수라 ±1, ±2 경계를 쓸 수 없음  

→ 실측 분위수(10/30/70/90%)로 5칸 분할  

→ 선행연구(Acoustic Cue Alignment, VowelPrompt)가 5분위 binning을 사용

### 1. 발화 100개를 어떻게 고르나

KconfSpeech에 3582 발화가 존재함

데이터 분포)

```
|z| < 1    약 70%    ← 평범한 발화
|z| 1~2    약 25%
|z| > 2    약 5%     ← 튄 발화
```

층화 추출: |z| 크기별로 나눠서 뽑습니다.

```
|z| 큰 발화     40개   ← 음향이 할 말이 많음
|z| 중간        30개
|z| 작은 발화   30개   ← 음향이 할 말이 없음

|z| 작은 발화는 평소와 똑같이 말한 발화를 의미함
```

여기에 추가로 연속 구간 길이(같은 화자가 몇 발화 연속으로 말했는가)를 재서 연속 구간 3이하로 걸러냈다.

```
전체 3582발화
      ↓
① 연속 구간 3 이하로 걸러냄    →  958발화
      ↓
② 이 958개를 |z| 크기로 층화   →  상/중/하
      ↓
③ 각 층에서 뽑음              →  40 / 30 / 30
```

여기서 가짜 음향 정보는 같은 층 안에서만 교환할 수 있게 설정함
