이전 실험에서는 단일 세션을 통해서 CER/WER 수치를 측정해보았다. 본 실험에서는 다중 세션으로 확장해서 "회의 환경 성능 저하"가 일반적인지 검증해보려 한다.

## 실험 흐름

1. S000011~S000019 데이터 로드 (9개 세션)
2. 세션별 ASR 전사 및 CER/WER 계산
3. S000010(0.433)과의 비교

## 실험 결과

### 1. 다중 세션 CER 통계

- 9개 세션 전체에서 mean-median 괴리가 공통적으로 관찰됨
- median 기준 실제 전사 성능은 0.17~0.33 범위 (세션 간 절대적 차이 작음)
- mean은 0.235~1.020으로 세션마다 크게 다름
- → 모델이 전반적으로 나쁜 게 아니라 **특정 발화에서 간헐적으로 환각이 폭발**하는 구조
- std가 큰 세션: S000011(2.819), S000019(2.726) — 극단값 존재하는 불안정 세션
- std가 작은 세션: S000016(0.298) — 환각 없이 고르게 작동하는 안정 세션

### 2. 다중 세션 시각화 확인

- 모든 세션의 median이 S000010 기준선(0.433) 아래에 위치 → S000010이 특별히 쉬운 세션이 아니었음
- S000016(std=0.298)은 9개 세션 중 가장 안정적

### 3. 환각 상위 샘플 분석 (CER 상위 20개)

**유형1 (프롬프트 누출+전사 거부)**: 모델이 오디오를 인식하지 못하고 "음성 파일을 업로드해주세요" 등 챗봇 응답 출력. 짧은 발화에서 집중 발생.

**유형2 (언어 붕괴)**: 한국어 대신 태국어, HTML 코드 출력.

**유형3 (내용 완전 대체)**: 오디오와 무관한 내용 생성.

### 4. 발화 길이 vs CER

- ref 길이 25자 이하 단구간에서 CER 극단값(최대 40) 집중 발생
- ref 길이 50자 이상 구간에서는 CER이 1.0 이하로 안정적으로 수렴
- → **환각 폭발의 주요 트리거: 짧은 발화**

### 5. 발화 길이 구간별 환각률

| 구간 | 환각률 |
|---|---|
| 10자 이하 | 70.5% |
| 11~20자 | 41.9% |
| 31~50자 | 4.7% |
| 51자 이상 | 1.3% 이하 |

**30자가 환각 발생의 실질적 임계값(threshold)**으로 작동함.

### 6. 짧은 발화 비율 vs 세션별 Mean CER

- 짧은 발화 비율(30자 이하)과 세션별 mean CER 사이에 양의 상관관계 확인
- S000019(short_ratio=0.53, mean=1.020) vs S000016(short_ratio=0.12, mean=0.235) — 가설과 완벽히 일치
- 단 S000011은 short_ratio=0.276이지만 mean=0.770으로 높아 짧은 발화 비율이 유일한 요인이 아님

## 결론

1. **S000010은 평균적인 세션이었다** → 07의 결과가 일반화 가능함을 확인
2. **회의 환경 성능 저하의 주범은 "간헐적 환각 폭발"** — median 기준 실제 성능은 세션 간 크게 다르지 않음
3. **환각의 핵심 트리거는 짧은 발화** — 30자 이하: 환각률 16~70%, 50자 이상: 1.3% 이하
4. **환각 유형 3가지**: 프롬프트 누출+전사 거부 / 언어 붕괴(태국어, HTML) / 내용 완전 대체
5. **짧은 발화 비율이 주요 요인이지만 유일하진 않음** — 음질, 화자 특성 등 추가 요인 가능성
