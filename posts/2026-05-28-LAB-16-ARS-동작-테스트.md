Gemma 4의 한국어 ARS 동작을 확인해보기 위해서 데이터가 필요하다.
우선 동작만 확인해보는 것이 목표기 때문에 처음부터 많은 데이터로 확인하는 것보다는 한국어 오디오 5~10초 정도를 가져와서 확인할 생각이다.

![](https://velog.velcdn.com/images/xorms/post/315bae9a-7d5e-47b8-b981-4c37f99e1257/image.png)

공개 데이터셋에서 1~3개 정도를 뽑아서 확인할 것이고,
claude code mcp를 통해서 데이터셋을 조사한 결과 *Zeroth-Korean*을 사용하기로 하였다.

### 사용 이유

- 소리를 컴퓨터에 저장하기 위새허는 샘플레이트(SR)을 활용 -> 1초 동안 소리 높이를 몇 번 찍어서 숫자로 기록하는 형태
  -> SR이 다르면 모델에 넣기 전에 모델의 SR로 계산해서 바꿔주는 작업 필요

#### 1. Gemma 4의 SR은 16kHz = Zeroth-Korean의 SR은 16kHz

#### 2. 가입 동의 없이 바로 다운로드 가능

#### 3. 가볍고 짧다 -> 동작 확인에 적합

## Gemma에게 소리를 건네주는 방식과 글을 돌려받는 방식

### 1. 소리를 어떻게 건네주나?

- Gemma한테 음성을 넣을 때, 코드에서 소리를 담는 칸의 이름은 audio
- 프롬포트: 두 가지를 같이 전달해야 함("받아써 줘"라는 말 + 음성 파일)
  -> 즉, messages의 content 배열에 {"type":"text"} + {"type":"audio"}를 나란히 전달

```python
messages = [
    {
        "role": "user",
        "content": [
            {"type": "text",  "text": "다음 한국어 음성을 받아써 주세요."},
            {"type": "audio", "audio": audio_array},
        ],
    }
]
```

### 2. 글을 어떻게 돌려받나?

- Gemma한테 "이 음성 받아써 줘" 하고 시키면, Gemma는 답을 돌려줄 때 내가 한 질문까지 통째로 다시 적어서 돌려줌
  ex.. 나: "이 음성 받아써 줘: (음성)" /  Gemma: "이 음성 받아써 줘: (음성) 안녕하세요 오늘 날씨가..."
- 즉,  출력 앞에 내 질문이 그대로 붙어서 나옴 -> 그래서 input_len을 저장하고 그만큼 잘라내는 슬라이싱 작업이 필요함
